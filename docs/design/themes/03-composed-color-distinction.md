# 主题与氛围的合成色区分

## 2026-10-15：微调氛围浓度

根据「再稍微浅点」的反馈，在回调版基础上再降低约 12% 的浓度。工作区浅色主光 / 辅光为 23% / 16%，深色为 21% / 14%，浅色石墨为 26% / 23%；锁屏浅色为 28% / 19%，深色为 26% / 18%。光场范围、色相、正文实底与现有回归要求保持一致。

## 2026-10-15：回调氛围浓度

根据「颜色又太重了」的反馈，保留全窗光场范围、相邻色过渡和静态抖动纹理，将工作区浓度降低约四成：浅色主光 / 辅光为 26% / 18%，深色为 24% / 16%；浅色石墨为 30% / 26%。锁屏调整为浅色 32% / 22%、深色 30% / 20%。正文和输入区域继续使用原有实底。

截图回归同时约束可见性与浓度：内容周围留白的开关平均色差介于 1.5 和 8，边缘色差大于 2.5，中部色差小于 10；八套主题辨识度、文字和按钮对比度、轻淡分割线检查保持不变。

## 2026-10-15：增强全窗氛围

根据「效果太弱，希望氛围更明显」的反馈，光场从较窄的上下边缘扩展到整张工作画布。主光移入 14% / 12%，辅光位于 95% / 95%，浅色强度调整为 42% / 32%，深色为 38% / 28%；中央叠加轻薄的中性亮面，侧栏与标题栏继续共用连续背景和原有的轻淡分割线。

每组强调色搭配相邻色反光：群青配蓝青、鸢紫配玫瑰、翡翠配浅绿，其余色组保持各自冷暖。锁屏强度为浅色 52% / 38%、深色 46% / 32%。加入静态的微弱抖动纹理，缓解大面积渐变的色带；没有持续动画、额外模糊层或指针跟随。

正文卡片、输入框保留实底；画布上的搜索与收起的书写区域也采用实底材质，避免占位提示因增强背景而变淡。弹窗与阅读书写面继续使用较弱的材质。石墨强调色在浅底下使用 48% / 44% 的覆盖量，补足中性颜色的氛围可见性。

回归改为检查内容周围留白的开关平均色差大于 3、边缘色差大于 5；保留全部主题辨识度、文字与按钮 4.5 对比度和分割线强度要求，并从截图检查搜索、书写占位提示的对比度。低彩度约束检查正文卡片，工作画布允许明显的氛围色。

## 2026-10-15：框架分割与连续面光

侧栏和标题栏统一使用文字色 3% 的框架分割线，标题栏继续透明叠在工作画布上，不再借用内容卡片的描边。设置导航、笔记侧栏等布局分界消费同一材质角色，内容卡片和输入框仍保留自身描边。

工作区柔光改为宽扁的顶光与下方反光：主光位于 14% / -8%，辅光位于 84% / 110%，尾部渐淡到 100%。颜色分别混入底色 35% / 40%，浅色强度 14% / 9%，深色 13% / 8%。光场有尺寸上限，主阅读区继续保持纯净；锁屏保留独立的宽柔光，所有氛围仍为静态背景。

实际截图回归增加标题栏、侧栏 1px 分割线与邻近表面的取色检查，色差小于 4.5；氛围可见性改取顶边、标题下方和底边，避免沿用旧圆形光斑的位置。正文中央、文字对比度与强调色辨识门槛保留。

## 2026-10-15：阅读底色与强调色重设计

绢改为低彩度米灰，雾改为轻微冷调的雾灰，夜抬升暗部为夜灰，苔改为偏中性的灰绿。四套正文画布的 Lab 彩度均低于 7；同步重配文字、面板、描边、侧栏、锁屏、代码与状态色。夜的正文与卡面对比度约 7.6，减少原先近黑蓝底与亮白文字的强反差。

强调色保留十个 ID，重新设计亮暗两极的主色及完整 17 槽：群青、翡翠、陶橙、鸢紫、洋红、湖蓝、橄榄、琥珀、绯红、石墨。蓝紫、红紫与红、绿与青、橙与金分开，旧选择继续生效。选中底、悬停、品牌渐变、选区和氛围装饰色同步调整；每对实际预览色块的 CIE76 色差须大于 20。

验证覆盖八套底色 × 十种强调色 × 氛围开关，检查低彩度正文、文字和按钮对比度、主题切换及预览一致性，另核对最大化、锁屏、阅读与书写面。网络直连筛选框的焦点环统一归外层，内部 input 不再重复绘制。

## 2026-10-15：主题合并与柔光收敛

当前保留纸、雪、绢、雾、墨、岩、夜、苔八种底色，移除「素色 / 冷暖配色」分组。暖灰合入纸、素白合入雪、炭黑合入墨；旧 ID 在初始化时迁移，强调色和背景氛围开关保留，不在读取时回写设置。桌面与 Web 共用注册表和预览令牌，打印导出改用雪的浅色令牌。

十种强调色和独立氛围开关保留，共 8 × 10 × 2 = 160 组。底色 96 槽与强调色 17 槽契约不变。

- 柔光颜色由装饰色 75% 混入当前底色；工作区主光 / 辅光强度为浅色 16% / 11%、深色 14% / 10%，实际染色约为前版一半。
- 主光移到左上、辅光移到右下，尺寸分别限制在 680 × 540 和 640 × 500 像素半径内；最大化后中央保留底色。微缩预览按自身尺寸缩放。
- 锁屏使用独立的宽柔光：浅色 24% / 16%、深色 22% / 14%。弹窗覆盖 70% 卡面底色，小记阅读与书写覆盖 65% 正文底色，减轻颜色干扰。
- 卡片、输入框继续使用实底；关闭氛围后所有表面恢复纯底。柔光保持静态。

当前合成回归覆盖全部 80 组配色的开关状态，检查内容边缘有柔光、正文中央接近底色、八种底色可区分，以及辅助文字和主按钮各状态对比度 ≥4.5。不再要求减淡后的背景独自区分每对强调色，强调色身份由控件与预览一致性测试覆盖。另以 1920 × 1080 截图核对锁屏、工作区、设置与小记阅读 / 书写。

## 问题

设置中的色点不同，叠到实际画布上却容易趋同。原紫罗主色偏蓝；氛围反复使用同一低彩度强调色，浮层再覆盖 60% 中性色。纸与雪、墨与岩的底色差也被柔光削弱。

以 1040 × 670 的同一主界面、15 处空白画布像素比较，原墨蓝与紫罗的平均 CIE76 色差只有 0.92–0.98。仅断言 CSS token 不同无法发现这个问题。

## 配色调整

| 轴 | 调整 |
| --- | --- |
| 纸 | 象牙白内容面、暖灰画布；描边与悬停同步调整 |
| 雪 | 保留中性瓷白与灰色明度台阶 |
| 墨 | 保留暖色深墨画布 |
| 岩 | 抬升为蓝灰板岩；文字、描边、悬停与文件占位色同步提亮 |
| 强调色 | 墨蓝、玉石青绿、赭橙、紫罗、玫红；主色及 hover、active、soft、品牌渐变等整族同步调整 |

仍为四种底色 × 五种强调色。底色 96 槽、按极性覆盖的强调色 17 槽不变；四套底色的缺省墨蓝与对应覆盖层一致。主题 ID、存储键和旧 ID 迁移不变。

## 氛围合成

`materials.css` 为每种强调色定义主光、辅光两个装饰色，控件色继续负责文字与交互对比。背景以透明度控制强度，不再直接把控件主色反复稀释。

- 主界面：两处 24% 径向柔光，去掉覆盖色相的中性光层。
- 浮层：中性色覆盖从 60% 降至 25%，仍以当前卡面作为实底。
- 锁屏：主光 24%、辅光 18%，保留较弱的中性提亮与现有呼吸动画。
- 设置缩略图：在自身 `.theme-scope` 中重算相同配方，按卡片尺寸缩放。
- 内容卡片和输入区域继续使用实底；关闭氛围恢复纯底，系统减少动态效果时停止装饰动画。

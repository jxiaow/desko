## 1. 现状与病根

1040×670（纸主题）实测：

| 项 | 数 | 说明 |
| --- | --- | --- |
| 首条小记之前 | **247px** | 页栏 64 + 书写器 141 + 书写器上间距 8 + 分组头 34 |
| 一屏可见小记 | **短记 4–5 张 / 中等 2–3 张** | 卡高 74–219，正文预算被 `--memo-max-h: 144px` 截住 |
| 读一条长笔记 | 点卡 → 编辑，或全屏 → 退出 | 卡上读不完；就地打开是**编辑**，不是阅读 |
| 视图与标签 | 右侧辅助目录，默认收起 | `preferences.open.notes ?? false`，最常用的筛选先要一次开关 |
| 每张卡上的物件 | 标题 / 时间 / 4 颗动作 / 标签脚注 / 勾选位 | 扫读时全在抢注意力 |

病根不是卡片样式，而是**捕获、扫读、精读挤在同一列**：列表要密、阅读要宽、书写要静，同一条 960px 流只能互相妥协。小记以短为主，所以本方案的第一收益是**捕获与扫读**；完整阅读只是顺带成立的极值，不是前提。

## 2. 方向：一列拆两列

```
┌ 56 ┬──────────── 索引 300 ────────────┬──────────── 正文 684 ────────────┐
│模块│ 搜索  / 视图 / 标签（列首不滚）  │ 44 首栏：标题 + 置顶 编辑 ⋯       │
│ 轨 │ 置顶 · 1                         │        ┌── 620 阅读列 ──┐        │
│    │ 今天 · 12                        │        │ 标题 18/600     │        │
│    │ 昨天 · 8                         │        │ meta · 标签     │        │
│    │ …                                │        │ 正文 14/24      │        │
│    │ 128 条 · 9 加密 · 12 归档        │        └─────────────────┘        │
└────┴──────────────────────────────────┴──────────────────────────────────┘
```

- **索引列只负责“找到那一条”**：搜索、视图、标签、日期分组、64px 行。
- **正文列只负责“读和写”**：44px 首栏 + 620px 阅读/书写列。
- **捕获不再是常驻书写器**：索引列首之外只留顶栏一颗「写一条」，点了在正文列起一张草稿。

不换视觉语法：仍是 56px 模块轨 / 48px 顶栏 / 同一套纸墨令牌 / 导航选中一律 `--sidebar-active` + `--text-brand` / 无入场动画 / 不新增主题槽。

## 3. 几何（1040×670）

| 件 | 值 | 依据 |
| --- | --- | --- |
| 索引列 | **300px** | 64px 行要同时放标题 + 一句预览；248px 会把预览挤成八个字。1040 窗下正文列仍有 684。 |
| 阅读列 | **620px** | 684 − 32（左衬）− 32（右衬 + 9px 滚动条槽，右衬写 23）＝ 620；@14px ≈ 44 个汉字一行。全屏现有的 `clamp(800px, 80%, 960px)` 在 684 里放不下，800 下限不能搬过来。 |
| 索引行 | **64px** | 与直连/Codex 的 `.rcard-row` 同档，正好放“主名 + 一句细字”。 |
| 索引行距 | **0 + 1px 发丝** | 平铺笔记列表，不是一列浮岛；行间 1px 内衬 12 的发丝，一屏 7 行。 |
| 正文首栏 | **44px** | 与全屏首栏、页栏同族。 |
| 正文起笔 | **首栏 44 + 24** | 标题上方留白 24。 |
| 索引列首 | **91–119px** | 上衬 12 + 搜索 32 + 8 + 分段 28 + 8 + 标签一行 20 + 下衬 10 + 发丝 1；无标签时 91。 |

- 页名左缘跟索引列内衬对齐（56 + 14 = **70px**），比全站 32px 内衬窄一档；这是本轮唯一的骨架偏移，因为索引列已经接管了页面左缘。
- **≥ 960px 内容宽**（≈ 1016 窗）：两栏并排。
- **< 960px**：正文吃满，索引转 300px 浮层盖在左缘；首栏左侧出现索引开关，点行即收起，默认收起。
- Web / 移动端本轮不动，继续走现有卡片流。

## 4. 索引列

### 4.1 列首（不滚）

1. **搜索 32px**：占满列宽，placeholder「搜索小记…」，`Ctrl K` 聚焦。搜索只筛索引，**不换正文**——正在读的那条不因输入搜索词被抽走。
2. **视图分段 28px**：全部 / 置顶 / 收藏 / 归档，四等分 12px 字。选中 `--sidebar-active` 底 + `--text-brand`，不加白块与投影（分段控件按导航选中方言走）。
3. **标签行**：20px 胶囊（`.tag-pill` 同款），带计数；**一行最多 4 颗，其余压成「+N」**，点开 `PopoverMenu` 列全部标签（240px 内滚动）。多选沿用 `activeTags`；选中颗 accent-soft + brand。没有标签时整行不出，不占位。
4. **归档上下文条**（仅归档视图）：24px 一行「归档中的 12 条 · 不出现在全部里」+「恢复全部」文字钮，替换现有 38px 的 `.archive-bar`。
5. 列首与列表之间一条 `--border` 发丝；列首不滚。

### 4.2 行

```
[勾选16] 标题 14/500 ..................... 时间 12
          预览 12px，一行截断
```

- 64px，`padding 0 12`，圆角 8，列面取 `--sidebar-bg`；**不吃卡面**：行透明、无描边、无投影，行间只用 1px `--border-subtle` 发丝（左右内衬 12）。
- 悬停 `--hover-chrome`（画布上的 chrome 档，见 [[project-chrome-hover-fill]]）；当前条 `--sidebar-active` 底 + 标题 `--text-brand`，**不加描边环**（与目录激活行同一语言）。
- 标题：`--text-base` 14/500 `--text`，一行省略；没有显式标题时用预览首句顶上。
- 预览：`--text-xs` 12 `--text-muted`，一行省略；锁着的行写「已加密 · 解锁后阅读」。
- 时间：12px `--text-muted`，右上，格式沿用 `formatRelativeTime`（刚刚 / 3 小时前 / 10-24）。
- 标记：置顶 `pin`、收藏 `star`、加密 `lock`，15px，排在时间左侧；最多两枚，挤不下时先舍收藏。
- 批量：只有 `pickMode` 时出现 16px 勾选，行左内衬 12→36；此时点行 = 选中/取消，不再换正文（与收藏页批量语义一致）。
- 键盘：行是 `div[tabindex=0]`；`↑/↓` 移动焦点并同步正文，焦点环 2px `--accent-ring` 内环。

### 4.3 分组与滚动

- 分组沿用 store：置顶 / 今天 / 昨天 / 本周 / 本月 / 更早。组头 28px、12/600 `--text-muted`，sticky top 0，底色取画布实色（不吃光晕）。
- 300+ 条用 `content-visibility: auto; contain-intrinsic-size: 64px`，**不做虚拟列表**（保住 Ctrl+F、读屏与「选中行不丢」）；组头吸顶提供方位。
- 列表 `overflow-y: auto; scrollbar-gutter: stable`，底部内衬 22px；批量时内衬加到 92px，给出坞让位（正文列同步让 70px）。
- 列尾固定 34px：左「9 加密 · 12 归档」，右 24px 口令锁（页面级口令从顶栏移到这里，避免和窗口锁定并排成两颗锁）；批量时整条让位给坞。
- 当前条离开列表（删除 / 归档 / 取消收藏）：选原位置的下一条，没有则上一条；列表空了正文列进空态。

### 4.4 极值

| 态 | 表现 |
| --- | --- |
| 300 条 | 只渲染视口附近；组头吸顶；滚动条常驻不横移 |
| 50 个标签 | 两行后收「+N」，PopoverMenu 内滚动 |
| 长标题 / 长预览 | 各一行省略，`title` 给全量 |
| 加载 | 5 行 64px 骨架（`--hover` 底），列首照常可点 |
| 空库 | 索引只留列首 + 一句「还没有小记」；正文列出空态 |
| 搜索无果 | 索引「未找到匹配的小记」+ 清空搜索；正文保留当前条 |

## 5. 正文列

### 5.1 首栏 44px

- 左：索引开关（仅窄窗）+ 当前分组（12 muted，如「置顶」）；正文标题滚出视口后换成标题（14/500），长文滚动时标题不丢。锁定的条首栏直接给标题（锁面板无标题）。
- 右：`置顶` · `编辑` · `⋯`（`.ib` 26px）。**编辑不是主按钮**——页面主按钮只有顶栏「写一条」。
- 加密条：首栏只有 `置顶` · `⋯`，`解锁` 落在锁面板（全列唯一入口，见 §5.4）。归档视图：`取消归档` + `编辑` + `⋯`。
- `⋯` 共用 `NoteMoreMenu`：复制正文 / 收藏 / 归档 / 导出 / 加密 / 删除；不重复首栏已有动作。
- 阅读全屏退到 `⋯`（「全屏阅读」）或本轮退役，见 §10。

### 5.2 阅读态

- 排版照搬全屏阅读：标题 18/600、meta 12、正文 14/24 `--text`、行内 code 12、`pre` 13、任务勾选走 global 配方、图片 `max-height: 34vh`。
- 620 列居中，上下 24 / 64；首栏与正文同底色，**阅读面不套卡、无描边、无投影**（画布即纸）。
- meta 行：`创建于 10-27 09:12 · 412 字`（与全屏阅读同配方）；标签走正文末尾的 `#tag` 胶囊，点标签 = 回到索引过滤。
- 长文：正文列独立滚动，首栏固定，索引选中不变。

### 5.3 书写态

- 入口：首栏「编辑」（已有条）或顶栏「写一条」（草稿）。标题/正文就地变编辑器，宽度、行首与阅读态**同一 620 列**，不换列位（沿用 10-26 读写同宽决定）。
- 首栏左变「书写中 · 自动保存」（或「新小记 · 未保存」）；右：`完成`（accent-soft）· `全屏` · `⋯`。
- 底栏 `NoteToolbar`：格式按钮 + 自动保存提示。`Ctrl+Enter` = 完成；`Esc` = 完成（已有条，修改可走编辑器历史回退）。
- **切行 / 切视图 / 进批量 / 进全屏前先 `flushNoteSave()`**；保存失败留在当前书写面并 toast，不切。
- 已有条的修改自动保存；草稿**不落库**，跨切行保留在 `noteDraftHtml`，`写一条` 再点即续写；`放弃` 才清空。草稿态里顶栏「写一条」置灰——同一时刻只有一个书写面。
- 发布成功后：清空搜索与标签、视图切回「全部」，新条落在榜首并被选中，索引滚到顶部。

### 5.4 加密

- 整库口令未开：索引给标题 + 锁；正文列落一根锁面板（锁盘 + 「已加密 · 输入口令阅读」+ 主按钮 `解锁`），首栏不再放第二颗 `解锁`。
- 整库已开：直接可读；首栏「重新锁定」收进 `⋯`，语义与现状一致。
- 归档视图不做批量加解密（现状）。

### 5.5 无选中 / 空库 / 加载

- 进入页面默认选 `filteredNotes[0]`（最近一条），正文列不空；上次选中不跨启动保存。
- 空库：索引列首照常（搜索/视图/写一条），正文列空态：图标 + 「还没有小记」+ 「点顶栏「写一条」起笔」——**不再放第二颗主按钮**，顶栏那颗是全页唯一入口。
- 加载中：索引 5 行骨架；正文列留白，不闪骨架。

## 6. 动作与键位

| 键 | 行为 |
| --- | --- |
| `Ctrl K` | 聚焦索引搜索 |
| `↑ / ↓` | 索引内移动当前条（焦点跟随），正文同步 |
| `Ctrl Enter` | 书写 / 草稿：保存 |
| `Esc` | 退书写（等同完成）→ 退批量 → 关窄窗索引浮层 |
| `Ctrl B` | 窄窗：开合索引浮层；宽窗不作用（见 §10） |

顶栏（`#workspace-page-toolbar`）只留：`写一条`（主按钮）、`选择`、`导出`。搜索从顶栏移进索引列，口令锁移到索引列尾。

## 7. 不变项

- 数据与筛选：`filteredNotes` / `groupedNotes` / `tagCounts` / `viewCounts` / `archiveSummary`、搜索口径、创建时间倒序、归档不进全部与搜索。
- 加密与口令：单条加解密、整库口令、重锁、删锁、切换档案。
- 导出：整页 / 单条 / 归档全量 / PDF / Word / 图片，导出控制器不动。
- 批量：`pickMode` 与 `hasSelection` 语义（有选中才出坞）、全选 / 取消全选 / 合并 / 批量删除 / 置顶 / 收藏 / 归档。
- 图片与附件：选图、粘贴、拖放、`stageImage` 草稿路径、删除附件。
- 编辑器：TipTap schema、斜杠命令、任务列表、撤销栈、粘贴链接、复制轨（plain 只出裸链接）。
- 全屏层：阅读 / 书写全屏、退出焦点恢复、`Esc`、宽度轴 `clamp(800px, 80%, 960px)`。
- Web / 移动端：现有卡片流 + 右侧目录不动。

## 10. 需要拍板

1. **右侧目录去留**：推荐小记退出 `hasWorkspaceDirectory`（视图/标签已进索引），`Ctrl+B` 只在窄窗开合索引浮层；宽窗常驻、不折叠。
2. **阅读全屏**：推荐桌面退役（正文列已能完整阅读），只保留书写全屏；Web 不动。若保留，收进 `⋯`。
3. **索引行形态**：推荐平铺导航行（透明底 + `--hover-chrome` 悬停 + `--sidebar-active` 选中），不再一列白卡。
4. **几何定稿**：索引 300 / 阅读 620 / 行 64。

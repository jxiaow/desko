# 小记：编辑与阅读的排版和编辑面 UI

日期：2026-10-30　状态：**已落码（2026-10-31 补全屏首栏清理，待提交）**
关联：[09-slip-stream.md](09-slip-stream.md)（便签流）、[10-editor-preview-enhancements.md](10-editor-preview-enhancements.md)（功能增强；其中 W1 选中条在本轮一并定形）

## 1. 病根

真帧取自 `1040×670` 与 `1440×900`，纸/墨两底色；当前实现与候选稿同机同内容对拍。

| 项 | 现尺 | 问题 |
| --- | --- | --- |
| 正文字号 | `--text-base` 14px / 24px 行高 | 和界面控件同字号，阅读面没有自己的声部，读起来像设置面板 |
| 行长 | `clamp(800px, 80%, 960px)`（1440 实测列宽 890px） | 一行约 63 个汉字，回行时丢行；短记在大窗里横向摊得过薄 |
| 段距 | `8px`，只有 1/3 行高 | 段落糊成一片，扫读找不到段落边界 |
| 标题层级 | 阅读标题 18 / h1 18 / h2 16 / h3 14 | 标题只比正文大 2–4px，层级几乎只能靠字重读 |
| 任务项 | `gap: 5px` + `li` 上下 4px 外边距 | 实测量出 34px 一行，任务清单比正文还散 |
| 编辑底栏 | 按钮 24 / 26px 混高，左缘贴窗 | 工具不落内容列，和正文左缘差 50px，读起来像两条不相干的栏 |
| 选中条 | 只有代码、链接两颗 26px 图标 | 加粗/斜体/删除线只能靠 Markdown 或快捷键；两个图标同灰度、同尺寸，靠猜 |
| 编辑态标题 | 首块 h2 16px（正文 14） | 阅读态标题 18px，点「编辑」标题当场缩水，「所见即所读」在标题上先破了 |

## 2. 排版尺度

全屏读写共用 `.note-doc`，一套数字同时管编辑和预览；卡片、书写条保持 14px 紧凑排版不动。

| 元素 | 新尺 |
| --- | --- |
| 正文 | 16px / 28px 行高 |
| 段落间距 | 14px（约半行） |
| 阅读列宽 | **680px** 固定上限（16px 约 42 汉字/行） |
| 阅读标题 | 24px / 34px，`margin-bottom: 10px`，字距 normal |
| 元信息行 | 12px / 18px，`--text-secondary`，上距标题 10、下距正文 22 |
| h1 / h2 / h3 | 22/32、18/28、16/26；上距 32 / 26 / 22 |
| 列表 | `padding-left: 24px`，`li` 上下 5px；任务列表 `gap: 8px`、`li` 不加外边距、勾选框上移 6px 对行 |
| 行内代码 | `0.875em`（14px），内距 2×5，圆角 5 |
| 代码块 | 13.5px / 22px，内距 14×16，圆角 10 |
| 引用 | 左边线 2px `--accent-light`，内距 16，字色 `--text-secondary` |
| 分割线 | 上下 26px |
| 图片 | 圆角 10，高度上限 56vh 不变 |
| 页内上下留白 | 36px（读写两态同值，切模式标题不跳） |

列宽 680 是对 10-26「读写共用 `clamp(800, 80%, 960)`」的修订：那条公式在 1440 把行长推到 60 字以上，字号一上 16px 更站不住；680 在 800 / 1040 / 1440 三种窗宽下保持同一行长，窗口宽度只改左右留白。

## 3. 编辑面 UI

### 3.1 选中条：五颗

```
[ B ][ I ][ S ] │ [ <> ][ 🔗 ]
```

- 顺序：加粗 · 斜体 · 删除线 ｜ 行内代码 · 链接；B/I/S 用字面形（不新增图标），分隔线 1×16px `--border`。
- 尺寸：按钮 28×28、圆角 7；条高 36（`min-height` 锁住，链接输入态同高），内距 3。
- 态：与代码/链接同一套 `.on`（`--accent-soft` / `--accent-active`）；按钮带 `aria-pressed` 与标题（Ctrl+B / Ctrl+I / Ctrl+Shift+S）。
- 定位：沿用现有「优先浮在选区上方」；`BAR_H` 30 → 36，`BAR_W_MAX` 268 → 300（链接输入态更宽）；合成输入期间不出条。
- 这一条同时是 10 号文档的 W1；交互口径（StarterKit 现成 mark、不加依赖）按那份文档，本文只定形态。

### 3.2 编辑底栏

- 撤销 / 重做 / 图片 / 标签统一 28px 高，间距 6；图标 14、文字 12。
- 底栏内容与正文同列：外层 `padding-inline` 与 `.fs-scroll` 一致（`--workspace-gutter`），内层 `max-width: 680px; margin: 0 auto`——工具左缘对齐正文左缘，右端提示对齐正文右缘。
- 底栏自己不在滚动容器里，要用 `overflow: hidden` + `scrollbar-gutter: stable both-edges` 镜像 `.fs-scroll` 的 9px 滚动条槽：只对齐内边距、不镜像槽，列没顶到 680 时工具列会向左多出 9px；只镜像槽、内边距仍用 `--space-5`，窄窗会多出 28px。
- 底栏不铺色、不画顶线的既有配方不动。

### 3.3 编辑态标题与阅读态同尺寸

- 全屏编辑的第一块若是 `h1/h2/h3`，按阅读标题排：24px / 34px，下距 22px。
- 阅读态标题本身 24px（原 18px）；元信息 12px 与正文分离，不再和标题挤成一块。

## 4. 极值

| 态 | 表现 |
| --- | --- |
| 800 窄窗 | 列宽取可用宽度（实测 608，小于 680），左右留白仍是 48；文字不横向滚动，底栏与正文同左缘 |
| Web/窄窗（`--workspace-gutter: 16px`） | 左右留白 16，列宽 100%，上下留白仍 36 |
| 长代码 | `pre` 横向滚动，不换行；行内代码不撑高行盒 |
| 超长标题 | 24px 自动折行，`overflow-wrap: anywhere` 保留 |
| 300 条列表 | 与排版无关，沿用现有渲染 |
| 深色主题 | 元信息取 `--text-secondary`（不用 `--text-faint`），12px 下对比度 ≥ 5.8:1 |
| 空小记 | 编辑态首块占位符 16px；全屏新写面同列同留白 |
| 加密小记 | 解锁后同排版；锁定态不入本层 |

## 5. 不变项

- 便签流、卡片、46px 书写条与卡面 14px 紧凑排版不动。
- `.note-doc` 只服务全屏读写；不做全局字号令牌调整。
- 无新依赖、无图标新增、无数据结构 / 清洗 / 导出 / 加密变化、无入场动画。
- 功能项 R1（阅读层勾任务）、R2（代码复制）、R3（图片灯箱）、R4（阅读回顶）仍按 10 号文档单独拍板，不并入本轮。

## 9. 全屏首栏清理（2026-10-31，已落码）

48px 首栏里挤了 6 段文字、5 种形状：`退出全屏` 后又跟一颗 Esc 键帽，读起来像同一句里断出两个标签；阅读态挂「只读浏览」，状态字和退出钮粘成一句；「编辑」夹在置顶/复制/⋯ 中间，主次只看得出颜色；系统簇（锁/最小化/关闭）与动作簇同灰度、贴得又近，一眼并成一排。

候选 A/B/C/D 真 token 对拍后选 **B 静音**（`mock-b-*.png`）：

| 项 | 落法 |
| --- | --- |
| 退出钮 | 去掉 Esc 键帽，`title="退出全屏 (Esc)"` 承载提示；按钮本身仍是图标 + 文字 32px |
| 阅读态状态字 | 不渲染 `.save-hint`——没有可保存的东西就不报状态；书写态照旧「自动保存 · N 字」 |
| 置顶 / 复制 | 只留 13px 图标，28×28 无底；可读名走 `aria-label`（置顶/取消置顶、复制正文） |
| ⋯ | 同为 28×28 图标钮，菜单职责不变 |
| 主按钮 | 编辑/完成收在动作排最右，32px 文字钮保持 `--accent-soft` 淡染；`margin-left: 3px` 与图标拉开一档 |
| 动作排节奏 | 首栏 `gap: 8px`（左组退出↔状态同档），图标钮 `margin-inline: 3px`，图标中心距 42px；置顶/复制/⋯/主钮一条排右贴齐 |
| 阅读态右贴 | 没有状态字时由 `.fs-exit { margin-right: auto }` 接过 auto 外边距 |

窄窗（`workspace-toolbar ≤ 520px` 与 `≤ 640px`）隐藏状态字的既有规则保留；`.fs-exit .kbd` 相关规则随键帽一起删除。

落点：`src/components/notes/NoteFullscreen.vue`（模板顺序 + 尺寸/间距）；`e2e/specs/notes.spec.ts`（阅读态无状态字、退出钮 title 含 Esc、无键帽、置顶钮 28×28、主按钮为末位）；`e2e/specs/workspace-notes.spec.ts`（⋯ 的 Tab 先到「编辑」再到正文标签，钉住新顺序）。

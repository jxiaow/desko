## 1. 范围

本轮收口小记模块「读、收、选」三条面：

- 阅读：全屏只读态的标题层级、字号行距、时间与标签。
- 归档：页头口径、文案、窄窗折行与空态。
- 批量：dock 常驻、动作收敛、卡面交互、最小窗适配。
- 连带：全库口令弹窗口径、时间口径、无标题内容显示、就地编辑的格式一致性、统一文案。

不动：`notes` 表结构、归档/加密/导出的数据通道、视图枚举、导出格式、卡片骨架。不引入回收站。

## 3. 拍板建议

### D1 全屏阅读（推荐按 §4.1）

- 标题：只有明确使用 H1–H6 格式的首块才提取标题，与列表共用；阅读标题 18/26/600。普通段落、引用和自动摘要不充当标题。
- 顺序：标题 → meta → 正文 → 标签 → 附件。
- 正文：14.5/24；h1 24/30、h2 18/26、h3 15.5/23。
- 标签：从正文剥掉，底部胶囊可点；点击关闭全屏并切换筛选。
- 备选：保持现状只放大字号（不解决标题消失）；或全屏直接复用卡片 14.5/500 标题（阅读尺度偏小）。均不推荐。

### D2 时间口径（推荐）

- `created_at` 继续做分组和排序；`updated_at - created_at > 60s` 视为「已编辑」。
- 卡片时间后加「· 已编辑」；全屏 meta 写「创建于 … · 已编辑 · N 字」，已编辑的完整时间放 `title`。
- `formatAbsTime` 跨年才补年份，全屏/导出/收藏详情同时受益。
- 备选：全部改用 `updated_at`。会让旧笔记跳到「今天」，破坏「按写下那天回看」的语义，不推荐。

### D3 文案统一（推荐）

- 小记是本地内容，统一用「保存」：发布 → 保存，未发布 → 未保存；`Ctrl+Enter 保存`。若坚持保留「发布」，则必须把「已保存」改成「已发布」并另立一条口径，二选一，不混用。
- 锁动作统一「锁定」：页栏「锁定全部加密小记」，菜单「重新锁定」保留，toast「已锁定全部加密小记」。
- 「单击」→「点击」。
- 「已置顶/已收藏」的按钮文案改成动作词「取消置顶/取消收藏」，状态由底色和图标表达。
- 归档空态改成「在任一小记的 ⋯ 菜单里选「归档」」。
- 影响：`NotesModule.test.ts`、`notes.spec.ts`、`web-access.spec.ts`、`ProfilesPane` 的提示语与 store toast 要同步；不改代码里的 `publishNote` 等符号。

### D4 批量态（推荐）

- 进入待选就常驻 dock；0 选态显示「已选 0 条 · 点小记选择」，只有全选/完成可用。
- 主视图可视动作收敛为：全选、取消全选、导出、归档、更多、删除、完成；置顶/收藏四态进「更多」。归档视图沿用现有动作集：全选、取消全选、导出、取消归档、删除、完成。
- 卡面：批量态隐藏 hover 动作；标签胶囊保留外观但不可点；Enter/Space 切换选中；进入批量先落盘并退出就地编辑；书写框收起。
- 去掉 dock 入场动画。
- 备选：保留 10 颗并横向滚动/折行。800 最小窗下都更差，不推荐。

### D5 口令弹窗（推荐）

- 标题「解锁全部加密小记」；说明「小记共用一把口令，解锁本次会话内的全部加密小记。」
- 删掉「输错不计数，不会锁定窗口。」；错误仍用弹窗内 `.dialog-err`。
- 恢复链接改「用主密码直接恢复」，点击即恢复（与现行为一致）。
- 首帧聚焦口令格；`mode` 变化时重新聚焦。

### D6 未命名（推荐）

- 无标题格式时，列表与阅读页均不渲染标题行，不用库内自动摘要补造标题。「未命名」仅作为没有辅助名称时的无障碍名称回退。

### D7 归档页头（推荐）

- 无关键词/标签时页名只显示 `N 条`；有查询时 `M / N 条`。
- lead：「已归档 · 不出现在「全部」列表，可在本视图搜索」。
- summary：「最近一次归档：今天 / 昨天 / N 天前」。
- bar 由定高 38 改为 `min-height: 38px` + 上下内距 + `flex-wrap`，窄窗允许折行。
- 空态：「在任一小记的 ⋯ 菜单里选「归档」，就会收进这里」。

### D8 侧栏脚注（核验后保留）

- 保留全库总数、加密数、归档数的原有口径与短文案；「全部」计数排除归档。两者无需强制相等，也不追加说明文字。

### D9 卡片就地编辑（按用户补充要求）

- 普通段落与引用维持正文样式，首段不单独加大或加粗；保留用户主动设置的粗体与引用格式。
- H1–H6 沿用编辑器自身标题格式。正文维持 14/1.6，只修正原先「与只读同字号」的错误注释。

## 4. 详细设计

### 4.1 全屏阅读态

结构：

```
.fs-doc
  .fs-title   18/26/600            仅明确标题格式的首块，可选
  .fs-meta    12 / muted           创建于 … · 已编辑 · N 字
  .fs-view    14.5/24              首块 display:none
  .fs-tags    胶囊行                从正文剥出的标签
  .fs-atts
```

- 首块标题：`src/utils/noteDisplay.ts` 仅识别 H1–H6，返回 `{ title, hideFirstBlock }`。没有标题格式则返回空标题，P、引用和库内摘要都不作为标题。含图片、任务、列表或代码的混排块保留在正文，避免提升文字时把内容一并隐藏。
- 隐藏首块用 `.fs-view.promoted > :first-child { display: none; }`，不删节点，保证任务勾选对位。
- meta：`创建于 {{ formatAbsTime(created_at) }}`；`edited` 时追加 ` · 已编辑`（`title` 为 `更新于 …`）；再接 ` · {{ wordCount(text) }} 字`。新草稿仍是「新小记」。
- 标签：`displayHtml` 改为 `resolveAssetHtml(stripTagsFromHtml(sanitizeNoteHtml(contentHtml)))`；标签由 `noteMeta(content_html).tags` 生成 `.fs-tags` 胶囊。点击 emit `tagClick`，父层先 `closeFullscreen()` 再 `toggleTagFilter(tag)`。
- 字号表：

| 元素 | 现在 | 改成 |
|---|---|---|
| 正文 | 13.5/23 | 14.5/24 |
| h1 | 24/26 | 24/30 |
| h2 | 18/24 | 18/26 |
| h3 | 15.5/22 | 15.5/23 |
| 标题 | 无 | 18/26/600，-0.02em |
| meta | 12 / muted | 12 / muted，位于标题下 |

段落距 10px、标题前距 14px 保留；纸面内边距 20×28px 保留。根据最大化阅读反馈，纸面随可用宽度展开：`max-width: clamp(800px, 80%, 1200px)`，窄窗受 `width: 100%` 约束，替代原先固定 800px 的要求。正文同步变宽，超宽屏保留行长上限，本轮继续保留。

### 4.2 归档

页名口径：

```ts
watchEffect(() => {
  const total = headTotal.value
  const count = isArchivedView.value && !hasQueryFilter.value
    ? total
    : hasActiveFilters.value ? `${filteredNotes.value.length} / ${total}` : total
  pageHead.setHead('小记', `${count} 条`)
})
```

- 归档无查询 → `3 条`；归档搜索/标签筛选 → `1 / 3 条`；置顶/收藏视图保持现有 `M / N 条`。
- bar 结构：`已归档` · 说明 · `ab-sp` · 「全部取消归档」。
- store 的 `archiveSummary` 改成「最近一次归档：今天 / 昨天 / N 天前」，不再用「最近归档在今天」。
- bar CSS：`min-height: 38px`、`padding-block: 6px`、`flex-wrap: wrap`、`row-gap: 4px`；`.ab-sp { flex: 1 }` 保留。
- 归档 toast：「已归档，可在「归档」视图找回」，不再写「侧栏」——工作区布局下归档住在目录，不在侧栏。
- 空态：「在任一小记的 ⋯ 菜单里选「归档」，就会收进这里」。

### 4.3 批量态

| 状态 | dock | 卡面 | 书写框 |
|---|---|---|---|
| 未进入 | 不渲染 | 正常 | 显示 |
| 待选 0 | 「已选 0 条 · 点小记选择」+ 全选/完成可用 | 勾选框显形；动作隐藏；标签不可点 | 收起 |
| 已选 N | 计数 + 全部动作 | 整卡选择；选中环 | 收起 |
| 归档视图 | 「取消归档」替代「归档」，不出现置顶/收藏的更多 | 同上 | 收起 |

主视图 dock：`已选 N 条 | 全选 | 取消全选 | 导出 | 归档 | 更多 ▾ | 删除 | 完成`。

- 「更多」用 `PopoverMenu` 锚在钮上，宽 148，四项：置顶、取消置顶、收藏、取消收藏。归档视图没有「更多」。
- 宽度预算（按 13px 全角估算）：计数 57 + 全选 62 + 取消全选 88 + 导出 62 + 归档 62 + 更多 62 + 删除 62 + 完成 62 = 517；分隔线/间隙/内距约 71 → 588；0 选提示额外约 118 → 706；归档变体约 614。800 窗上限 760，留 50px 余量。落码后仍要 800×670 实拍复核。
- 页栏钮与卡片勾选两条入口均先 `flushNoteSave()` 并退出就地编辑，再进入批量。保存失败则保留编辑面与当前修改，不进入批量。
- 卡面：`.memo-acts` 在批量态不渲染；`.memo.batchable .memo-tags { pointer-events: none; }`，胶囊保留外观但不接点击；`article` 在批量态带 `aria-pressed`，Enter/Space 不再 return，改为 `emit('select')`。
- dock 去掉 `animation: dock-in` 与 keyframes；只保留静态定位。
- 0 选态：导出、归档/取消归档、更多、删除全部 disabled；「全选」选 `filteredNotes`；「完成」退出。
- 批量退出仍走 `exitNoteBatch`（页栏钮、Esc、dock 完成）。

普通首段与后续段落使用相同的正文排版，不添加 `:first-child` 字号或字重覆盖。只有用户设置的标题格式显示为标题，主动加粗与引用格式继续保留。

### 4.7 无标题与侧栏脚注

- 列表和全屏阅读都只显示正文中的明确标题格式。无标题时不渲染 `.memo-title` / `.fs-title`，不将 `note.title` 自动摘要显示成标题。
- 无标题列表卡片不预留标题栏高度，正文从卡片顶部内边距直接开始；时间、状态和操作保持右上角。正文开头避让控件，后续文字恢复完整宽度，悬停时也不遮挡正文；带明确标题格式的卡片保留原标题栏。
- 自动摘要继续用于搜索、辅助名称和现有数据通道，未改变库内内容、导出格式或加密规则。
- 侧栏脚注保留原有全库总数、加密数与归档数，不增加常驻解释行。

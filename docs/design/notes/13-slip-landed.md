## 3. 卡面配方（落地档）

| 项 | 纸片档（12 §4） | 落地档（本轮） |
| --- | --- | --- |
| 描边 | `1px solid transparent`（只占位） | `1px solid var(--border-card)`（纸底 `rgb(15 23 42 / 7%)`，墨底 `rgb(255 255 255 / 8%)`）——与全 APP 其它卡面同一条线 |
| 静影 | `--slip-shadow` | **删除**，卡面 `box-shadow: none` |
| hover | 抬影到 `--slip-shadow-hover` | 边转 `--slip-line-hover`（`color-mix(text 22%)`），背景不洗、不位移 |
| editing / focus-visible | accent 边 + 3px 光圈 + `--shadow-sm` | accent 边 + 3px 光圈（去掉 `--shadow-sm`，影归零就要归零） |
| 圆角 | `--radius-slip: 14px` | 不动 |
| 书写条 `.composer` | 与卡同档（transparent + 近影） | 与卡同档（发丝边 + 无影），聚焦仍是 accent 边 + 光圈 |

两处取值理由：

- **静息复用 `--border-card`，不新建令牌**：小记卡和收藏卡、文件卡本来就该是同一条线；上一轮为了「靠影不靠框」把线撤了，结果是小记成了全 APP 唯一没有边的卡面，这本身就是「不专业」的来源之一。
- **hover 不复用 `--border-card-hover`（12%）**：其它卡 hover 时是「线加深 + 影变大」两件事一起发生，小记把影摘掉后只剩线，12% 对 7% 那 1.7× 撑不住；22% 是拍帧后能一眼看出变化的最低档。线一律取 `--text` 的混合而不是固定灰，纸墨两底自动同权。

## 4. 对「线 + 影成对」的例外声明

`src/styles/workspace-themes.css:27-29` 立的规矩是：**线说边界在哪，影说它浮在上一层，任何一边归零卡片就糊进背景**。本轮在小记这一档**有意只留线、影归零**，理由是那条规矩的前提在这里不成立：

1. 它的适用对象是**浮岛卡**——稀疏摆放的 280px 网格卡，影有独立的落影空间。小记是一排排 12px 间距叠起来的纸片，影在卡间连成灰带，说的不再是「浮起」而是「脏」。
2. 小记卡与画布的分离本来就不靠影：白卡面 `#ffffff` 对纸底画布 `#fafafa`、对浮片 `#f7f7f5` 都有实底差，卡间还有 12px 通道。线在这里只负责把边界钉住，不负责独自撑起层次。
3. 破例范围仍是**小记一页**（`.memo` / `.composer` 两个类），令牌也只此一处消费。全局卡档、收藏、文件、直连清单照旧线+影成对，不得援引本例外。

## 5. 分类栏配方

1. **归位**：`.workspace-workbar-tabs` 与 `.wb-tags` 由 `flex: 1` 改 `flex: none`，页签按内容宽排，标签紧跟其后。收藏页共用这条规则，但它页签后面没有第二段，位置不变。
2. **全显或全收**：整组标签放得下就全显；放不下就**整组**收成一枚「标签 N ▾」（N = 标签总数）。判据是实测宽度（标签条按内容宽量一次，与分类栏可用宽比），不再按视口档位猜个数。**任何情况下都不出现「挑几个 + 更多 N」的半截列表。**
3. **已选常驻**：收起态下已选标签仍然显示在条上（否则看不出当前在筛什么），样式换成 `--accent-soft` 药丸 —— 与弹出层里 `.pop-item.on` 同一档 —— 并去掉 `.wb-tab.active::after` 的下划线：下划线是视图页签的身份，标签复用会被读成「第二个全部」。
4. **入口不可挤丢**：「标签 N ▾」`flex: none`，药丸 `min-width: 0` + 省略号，窗口再窄入口也点得到。
5. **分隔符**：1×15 `--border` → 1×16 `color-mix(text 16%)`（纸底约 1.38:1，能看见但不成一条线）。
6. **弹层不动**：搜索 + 复选 + 220px 滚动区 + `scrollbar-gutter: stable`；收起态下列出全部未选标签。分类栏高度恒定 42px，标签再多也不加行、不横向滚。

## 6. 被否与不动

- **被否，本轮及后续都不做**：卡面收 720 阅读轴（判词「卡片需要宽」）、页边日历 + 纸片列、F1/F2/F3 三骨架、连续白面 + 行间发丝线、双栏索引、日期章节/时间轴、多列卡墙。
- **不动**：卡宽满幅、卡内正文 720 行长（12 §8 落的容器查询，被否的是把**卡面**也收进 720）、三行声部（15/22·600 标题 + 14/22·400 正文）、`--memo-max-h: 66px` 与截断渐隐、`--radius-slip`、卡内标签仍是文字不是胶囊、全屏阅读层的 960 轴、hover 不洗底。

量法：`.tmp/notes-landed-20261102/verify.mjs` 直读真 app、**零注入样式**（改的就是源码），纸墨两底 × 1040/1440，帧在同目录。

| 判据 | 实测 |
| --- | --- |

| 已选药丸 | 底色 `color(srgb .22 .50 .29 / .1)`（accent 10%），`.active::after` 的 `display: none` |
| 横向溢出 | 分类栏 `scrollWidth <= clientWidth` 在 1440 / 1040 / 全显 / 收起四态全部成立 |

**落码坑（已修，留档）**：药丸若允许 `flex-shrink`，标签条的 `scrollWidth` 会跟着一起缩，整组永远判成「放得下」——展开态必须 `flex: 0 0 auto` 一颗都不缩，只有收起态（`.wb-tags.is-collapsed`）才放开收缩，让「标签 N ▾」入口在窄窗下也点得到。

**量法坑（走查脚本，已修）**：半透明淡底的对比度必须在**空画布**上量 alpha 再逐层合成；叠到不透明底上再读 `getImageData`，alpha 永远是 1，`--accent-soft` 会被当成实底，已选药丸会被误算成「主色铺在白底」的 1.8:1。修正后实测纸底 5.56、墨底 6.21（`contrast.mjs`）。

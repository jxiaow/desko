# 小记页：单列便签流

日期：2026-10-30　状态：**已实现**（本轮按 10-30 已出 mock 落码，五条默认全采纳）
关联：[04-action-dock.md](04-action-dock.md)（卡排收敛）、[08-two-pane-surface.md](08-two-pane-surface.md)（作废：双栏/多列均被否）、[../workspace/01-desktop-layout.md](../workspace/01-desktop-layout.md)（外壳与阅读列）

## 1. 病根

小记以短为主，列表页的第一收益是**捕获与扫读**，完整阅读只是顺带成立的极值。旧单列卡流把三件事挤在同一条 940px 里：

| 项 | 旧态 | 问题 |
| --- | --- | --- |
| 首条小记之前 | 页栏 64 + 书写器 141 + 间距 8 + 分组头 34 = **247px** | 1040×670 首屏只剩 400px 给列表 |
| 日期章节 | 今天 / 昨天 / 前天…每组 34px 头 + 12px 组距 | 小记一天就那么几条，章节把流切成一截一截 |
| 卡正文 | `--memo-max-h: 144px`（约 6 行），截断后冒「展开全文」 | 卡面既不够扫读也不够读完，多一个半截状态 |
| 读一条 | 悬停点眼睛 → 全屏阅读；点正文反而进编辑 | 阅读入口藏在悬停里，正文点击语义反了 |
| 卡上动作 | 全屏 · 编辑 · 置顶 · 复制 · ⋯ 五颗 | 眼睛与「点正文阅读」是同一动作的两个入口 |
| 空书写器 | 常驻三行 + 工具栏 = 141px | 不写的时候也占掉首屏四分之一 |

## 2. 结构：一列连续的纸片

```
┌ 工作栏：全部 12 · 置顶 2 · 收藏 1 · 归档 3 ─────────────┐
│  [ 记一条…                                        ＋ ] │  46px 收起态
├────────────────────────────────────────────────────────┤
│  ⌖ 置顶  2                                             │  18px 小标
│  ┌ 置顶小记 A ──────────────────────────────────────┐   │
│  └─────────────────────────────────────────────────┘   │
│  ┌ 置顶小记 B ──────────────────────────────────────┐   │
│  └─────────────────────────────────────────────────┘   │
│  ┌ 最新一条 ───────────────────────────────────────┐   │  卡距 10px
│  └─────────────────────────────────────────────────┘   │
│  ┌ 下一条 ─────────────────────────────────────────┐   │
└────────────────────────────────────────────────────────┘
```

- **没有日期章节**。置顶只在最上面换一条 18px 小标（图钉 + 「置顶」+ 计数），不吸顶、不描卡、不加底色；置顶卡卡头另缀一枚小图钉，滚过小标也认得出。
- **一列到底**：按创建时间倒序，置顶条仍按时间排在最前，与旧分组的条目顺序一致。
- **列宽 940**：壳层 `--workspace-content-max` 已对小记页给 940（与 Codex 页同档），本页不再自带第二套宽度轴。

## 3. 书写条 46px

| 态 | 表现 |
| --- | --- |
| 空 · 本轮未落笔 | **46px 一行**：placeholder「记一条…」，右端一枚淡加号（装饰，不接指针）；工具栏不出现 |
| 指针按下（仍空） | 展开为三行 94px，工具栏从下沿长出来；按钮始终在指针落点之外，不会点到一半被抽走 |
| 有内容 | 保持三行起，内容撑高，46vh 封顶；工具栏常驻（不只聚焦时） |
| 发布 / 放弃 / 删干净 | 回到 46px——光标还在条里也收，这是这一轮写完了的信号 |
| 空着失焦 | **不收回**（已修订）：原写「空 + 失焦收起」，实测失焦发生在 mousedown 那一刻，高度当场收掉，同一颗点击的 mouseup 落到别处——卡排上的 ⋯ 就此点不中。收起只由「本轮未落笔 + 正文为空」决定，焦点不参与 |

加号只说明「这里能写」，不承担点击：点它等于点书写条，焦点落进正文。

## 4. 卡：三行预算，点正文读全文

- **正文预算 72px（三行）**，沿用按整块边界截断的 JS：上限取最后一个完整子块的下边界，首块超高按整行切。首块被提升为标题行时，第二块的 8px 段距归零，不挤掉一行。
- **删掉「展开全文/收起」**：短记三行内一眼读完；读不完的进阅读层。卡面不再有半展开态。
- **点正文 = 阅读**（全屏阅读层），标题行、附件数同样算正文；不落在勾选框、链接、标签胶囊、动作排上时生效；拖选文字不触发。`Enter` / `Space` 同义。
- **勾选框仍是真控件**：点击落库，行为同前。
- **hover 动作四颗**：编辑 · 置顶 · 复制 · ⋯（归档视图：编辑 · 取消归档 · 复制 · ⋯；锁着的条：解锁 · ⋯ 两颗不变）。眼睛退役，动作排不再有第五颗。
- 置顶卡不描强调色边：置顶已有小标和图钉，描边会被读成「选中」。
- 列表容器不再吃 `card-fade-in`：翻页/切视图不放入场动画。

## 5. 极值

| 态 | 表现 |
| --- | --- |
| 300 条 | 单列，卡面 `content-visibility` 不额外加（沿用现有渲染）；滚动条常驻不横移 |
| 全置顶 | 小标「置顶 N」+ N 张卡，无日期段 |
| 全空库 | 书写条仍在首屏；空态文案与「清空筛选」入口不变 |
| 长正文 | 卡面截三行，全文只在阅读层；不出现「展开全文」 |
| 搜索/标签/视图 | 小标计数随筛选结果变；无置顶结果时小标整条不出现 |
| 归档视图 | 不出书写条；动作排把置顶换成取消归档 |
| 窄窗 800 | 与 1040 同构，列宽随内距收；书写条仍是 46px |

## 6. 不变项

- 数据与筛选：`filteredNotes` / 视图 / 搜索 / 标签 / 归档口径、创建时间倒序。
- 加密、口令、导出、批量、合并、图片与附件、编辑器与全屏层全部不动。
- 阅读层与书写层共用的 `.note-doc` 排版不动。
- Web / 移动端沿用同一张卡与同一套点击语义；移动端「全屏查看」仍在 ⋯ 的移动动作组里。

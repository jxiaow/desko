# 全高辅助目录与视觉排版审计

状态：已按核验结论实施；原始审计记录保留，最终范围见末节
日期：2026-10-20
范围：桌面工作区（paper / ink 两套底色）；Web 运行时不在此次范围
基准：1040×670 默认窗口真机页面，1440 宽窗复核；数据来自本地 e2e mock
关系：延续 [01-desktop-layout.md](./01-desktop-layout.md)；本文只改目录的垂直锚定与排版，停靠策略、宽度、默认收起和持久化键不变

以下发现和几何数据是实施前基准，不代表当前实现。评审后保留关闭 X、卡片标题 500 字重、不同内容流宽度、空标签提示和未来时段淡灰填充；最终实现以末节及 01 文档为准。

## 结论

目录本身的功能没有问题，问题出在它的起点：工具栏是整面通栏的一行，目录被放在工具栏下方，于是 200px 宽的侧栏从按钮下面才开始，顶部空出 64px。目录应该和工具栏同高起步，成为内容面右缘的一根全高列，而不是工具栏的下一行。

审计还发现六类视觉/排版问题：页面骨架高度在 60/64/66px 之间漂移；搜索框宽度在 320/360 之间反复；字号角色靠 12/13/14 三个相邻档位硬分，标题反而比目录项还轻；文件页文件夹行多一枚「目录」标签；Codex 的两组页签同排同字号；墨色卡片上的 12px 辅助字低于项目自定的 5.8:1 基线。

另有一处确定的视觉缺陷不在排版层：局域网传输、内网穿透运行中的「停止」按钮被工作区主按钮规则覆盖成绿色，失去危险态。应最先修。

## 审计口径

- 只记录当前页面真实可见的差异，不回填已修复的弹窗、下拉、空态问题。
- 结构判断以 DOM 与计算样式为准，不看静态截图猜。
- 对比度按 sRGB 相对亮度计算；浅色正文 4.5:1、深色小字 5.8:1 为项目基线。
- 截图与探针脚本留在 `.tmp/review2`、`.tmp/review`，不进入仓库。

## 布局问题

### P0 停止按钮失去危险态

局域网传输与内网穿透的启停按钮带 `ghost-danger` 意图：

- `FileShareModule.vue`：`btn-primary toggle-btn` 在运行时加 `ghost-danger`
- `TunnelModule.vue`：`status?.alive` 时加 `ghost-danger`
- 两个模块都写了 `.toggle-btn.ghost-danger { background: var(--danger-soft); color: var(--danger); border: 1px solid var(--danger-border); }`

但工作区壳在 `CodexWorkspace.vue` 末尾用更高优先级覆盖了页栏主按钮：

```css
.codex-layout .workspace-main .page-bar .btn-primary:not(:disabled) {
  background: var(--bg-workspace-primary);
  color: var(--text-workspace-primary);
}
```

实测局域网传输运行中的按钮：背景 `rgb(56, 128, 75)`（celadon 强调色）、文字白色、边框 `rgb(234, 207, 200)`（危险色边框），类名仍是 `ghost-danger`。绿色按钮配红色描边，既不是主按钮也不是危险按钮。

修复：把工作区的三条主按钮规则加上 `:not(.ghost-danger)`，让危险变体自行接管；不要提高 `ghost-danger` 的特异性来打补丁。验收时启动一次传输，按钮应为浅危险底 + 危险文字，并确认停止动作仍可用。

### P1 目录从工具栏下方起步

1040×670 的实测几何：

| 区域 | 当前 | 目标 |
| --- | --- | --- |
| 内容面 | x56 y42 w978 h625 | 不变 |
| 工具栏 | y42 h64，横跨整个内容面 | 只占正文列，y42 h64 |
| 目录 | x834 y106 w200 h561 | x834 y42 w200 h625 |
| 目录头 | y106 h40 | y42 h64 |
| 目录内容首行 | y146 | y112（内容区从 y106 起 + 6px 上内距） |
| 有目录时的正文列 | 778px | 不变 |

```text
当前：页栏横跨整个内容面，目录从页栏下方开始
┌─ 页栏 ──────────────────────────────┐
│ 搜索                     ＋  目录钮 │ 64
├──────────────────────────┬──────────┤
│ 正文                     │ 目录头40 │
│                          │ 列表     │
└──────────────────────────┴──────────┘

目标：页栏只占正文列，目录与内容面同高
┌──────────────────────────┬──────────┐
│ 搜索             ＋ 目录钮│ 目录头64 │
├──────────────────────────┤ 列表     │
│ 正文                     │          │
└──────────────────────────┴──────────┘
```

根因在结构：`#workspace-page-toolbar` 和 `.workspace-body` 是 `.workspace-main` 里的上下两行，`aside#workspace-directory` 被放在 `.workspace-body` 内部。目录因此天然从工具栏底边开始，永远晚 64px。

附带的视觉后果：

- 工具栏右端的加号、目录切换钮悬在目录正上方，目录头变成「第二行工具区」。
- 目录切换钮的 tooltip 向下展开，实测在墨色主题里直接盖住目录标题、固定钮和关闭钮（见 `.tmp/review2/rail-entries-ink-open.png`）。
- 目录的左描边只从 y106 开始，内容面右侧少了一整段竖向分隔，200px 的色块像贴在下半屏。

### P1 页面骨架高度与搜索宽度不齐

同一套 `.page-bar` 在真实模块里的高度：

| 模块 | 页栏高度 | 搜索框最大宽 | 首屏动作钮 |
| --- | --- | --- | --- |
| 小记 / 收藏 / 文件快捷 | 64px | 320 / 360 / 360 | 28px |
| 验证码 | 60px | 无搜索 | 28px |
| Codex | 66px | 320 | 28px |
| 局域网传输 / 内网穿透 | 64px | 无搜索 | 32px |
| 网络直连 | 无 `.page-bar`，首行 36px | 无 | 36px |

`.page-bar` 只写了 `min-height: 64px` + 上下 16px 内距，高度由内容顶出来：28px 的创建钮得到 60px，34px 的页签得到 66px。名义 64px，实际每切一个模块内容起点漂 2–6px。

搜索框的基础规则是 360px（工作区壳），小记与 Codex 各自压到 320px、文件与收藏继承 360px。切模块时搜索框右缘横向跳动，工具栏的视觉重心跟着变。

建议：把页栏高度固定为 64px（控件不超过 32px），搜索框统一 360px；网络直连作为无页栏的特例，在文档里写明，避免下一个模块继续分叉。

### P2 宽窗内容列分叉

`--content-max` 是 `clamp(900px, 100vw - 800px, 1120px)`，小记另用 `--stream-max: 1200px`。1440 宽窗实测：

- 有目录时正文列 1178px，小记内容 1130px（受 1200 上限约束）
- 收藏 / 文件快捷内容 900px（900 的下限）

两者差 230px。默认 1040 窗口看不出，宽屏切模块时正文和页栏会横向收放。建议把内容页的最大宽统一到 1120px（小记可保留自己的行长上限，但页栏跟内容页同宽），或在设计文档里明确「小记是阅读流、其他模块是卡片流」的双档理由，避免成为隐性分叉。

### P2 验证码的空页栏

验证码页栏只有一个右对齐的 28px 加号，占满 64px 高，横向没有搜索或筛选。标题栏已经写了「4 个账号」，页栏因此像一条空带。

建议二选一，并在 01 里定死：

1. 无搜索的模块允许页栏压到 44px，加号仍右对齐；
2. 保留 64px，但把「4 个账号」的摘要放到页栏左侧，和加号形成一条真正的操作行（标题栏不再重复计数）。

推荐第 1 种，改动小，也不破坏统一骨架的语义。

## 全高目录设计

### 目标结构

目录从 `.workspace-body` 里移出，成为 `.workspace-surface` 的直接子列。工具栏留在 `.workspace-main` 内，因此只占正文列。

```html
<div id="workspace-surface" class="workspace-surface directory-docked">
  <main class="main-area workspace-main">
    <div id="workspace-page-toolbar" class="workspace-page-toolbar"></div>
    <div class="workspace-body"><div class="main-content"><slot /></div></div>
  </main>
  <aside id="workspace-directory" class="workspace-directory">
    <div class="workspace-directory-heading">视图与标签 · 固定</div>
    <div id="workspace-directory-content"></div>
  </aside>
</div>
```

`.workspace-surface` 已经是 flex 行，`.main-area` 已经是 flex 列；这次只移动一个节点，不需要重写主布局。

### 几何

- 目录宽度 200px，贴合内容面右缘、顶部与底部；左上、左下直角，右上、右下继承内容面 14px 圆角。
- 目录头高 64px，与页栏同高；标题与动作垂直居中。
- 左描边 1px 从内容面顶边连续到底边，中间不断开。
- 正文列 = 内容面宽 − 200px；目录收起时恢复全宽。停靠方式不变，不做遮罩、不做浮层。
- 目录内容独立滚动，头部固定；`scrollbar-gutter: stable`，滚动条出现时行宽不横移。
- 页面工具栏的居中公式去掉 `--workspace-docked-width` 减法，直接按正文列计算：

```css
.workspace-page-toolbar {
  padding-left: max(var(--page-gutter), calc((100% - var(--workspace-toolbar-max)) / 2));
  padding-right: var(--page-gutter);
}
```

### 排版

| 元素 | 当前 | 目标 |
| --- | --- | --- |
| 目录标题 | 12px / 500 / muted | 13px / 600 / secondary |
| 目录项 | 13px / 400，选中 500 | 不变 |
| 计数 | 12px / muted，右对齐 | 不变 |
| 分组标题（标签 / 分类） | 12px / muted | 12px / 500 / muted |
| 空态、脚注 | 12px / muted | 12px / muted，行高 1.6 |
| 选中底 | `--bg-surface` 实底 + 2px 强调竖线 | `--bg-workspace-selected` + 2px 强调竖线，和侧栏同一种选中语言 |
| 行高 | 32px，间距 2px | 不变 |

标题当前比目录项小一档、轻两档，扫视时目录像没有标题。改成 13/600 后与侧栏的分组标题同级，仍低于页名，不会抢首屏。

文案改为角色名，去掉和页面重复的信息：

- 小记：`小记` → `视图与标签`
- 收藏：`收藏` → `收藏分类`

两处 `aria-label` 已经是这两个词，视觉标题改为同词即可，读屏与视觉不再各说一套。

### 交互与去重

- 保留：固定、外部点击收起、Escape 收起、Ctrl+B、窄窗选择后自动收起。全部沿用现有逻辑。
- 关闭入口收成一个：工具栏的目录切换钮（展开态已有高亮和「收起目录 (Ctrl+B)」提示）。目录头不再放 X，避免 200px 内出现两个关闭动作；01 中「可通过关闭按钮手动收起」改为「通过工具栏目录按钮或 Ctrl+B 收起」。
- 固定钮保留在目录头右侧；展开时显示 `unpin`，并继续持久化 `workspace_directory_pinned`。
- 目录收起时 `v-show` 隐藏，不卸载编辑器，状态不丢。

### 空态与滚动

- 标签数为 0 时，只保留分组标题 `标签 0`，不再额外渲染「还没有标签」一行；分组本身可以点击展开/收起时再补提示。
- 小记脚注 `共 N 条小记 · X 条已加密 · Y 条归档` 保留，住在内容流末尾；标签多时随内容滚动，不吸底。
- 顶部内距 6px，左右 8px，底部 12px；第一条目录项对齐内容首行。

### 主题

- 目录底色继续用 `--bg-inspector`：paper `#f7f7f6`，ink `#1b1c1f`；正文 `#fcfcfc` / `#18191b` 的层次足够，不另造色。
- 左描边 `--border`；选中底 `--bg-workspace-selected`；悬停 `--bg-workspace-hover`。
- paper 下目录标题 `--text-secondary` 对 `#f7f7f6` 约 7.4:1；ink 下 `#adb3bd` 对 `#1b1c1f` 约 8.1:1，均高于小字基线。
- 底部柔光随 `--bg-inspector` 的氛围光公式走，全高后从右下角向上铺，不额外加阴影。
- 不加圆角外框、不加卡片阴影、不做滑入动画。

### 响应式

- 停靠策略不变：所有窗口宽度下都与正文并排；最小 800px 窗口也保持 200px 目录。
- 窄窗（<1100px）继续走现有 `directoryCompact`：选中目录项后收起，固定后不收起；正文仍可点击。
- 页栏在窄窗允许换行，但目录头固定 64px；两者只在页栏换行时不再严格同高，这是可接受的降级。

### 实施点

- `src/components/layout/CodexWorkspace.vue`：把 `aside` 移到 `</main>` 之后；改 `.workspace-surface` 的子项关系；目录头 64px；标题文案与字重；选中底；隐藏 X；`scrollbar-gutter`；删除 `--workspace-docked-width` 与工具栏左侧减法；P0 主按钮规则加 `:not(.ghost-danger)`。
- `src/App.vue`：无需改状态流转；`directoryCompact`、固定、持久化原样传入。
- `src/components/notes/NotesModule.vue`、`src/components/entries/EntriesModule.vue`：Teleport 目标 ID 不变，不改模板。
- `docs/design/workspace/01-desktop-layout.md`：批准后补「贴合顶部」、64px 目录头、单一关闭入口三句。

### 验收

1. 1040×670：目录顶边与内容面顶边同为 y42；目录头 64px；左描边连续到底；右上角为 14px 圆角。
2. 页栏搜索、加号、目录切换钮全部在目录左侧，tooltip 不再覆盖目录标题。
3. 开合目录时正文列在 778px 与 978px 之间切换，卡片列数不因目录开合额外抖动。
4. 目录内容独立滚动，滚动条出现/消失时行宽不横移。
5. paper/ink 各拍一帧：标题 13/600，目录项 13，计数 12，选中底与侧栏一致，无入场动画。
6. 小记与收藏的目录状态在重启后恢复；固定、外部点击、Escape、Ctrl+B 行为不变。
7. 标签为 0 时只有一行分组标题，没有多余的「还没有标签」。
8. 局域网传输运行中停止按钮为危险态；内网穿透同样通过。

## 视觉与排版发现

### 字号角色需要一次收口

现有字号档位 12 / 13 / 14 / 15 相邻，实际页面主要靠字重和颜色分层：

- 目录标题 12/500，目录项 13/400，标题反而更轻。
- 小记正文 13，收藏名称 14/600，文件行名称 14/600，同一种「行标题」在不同模块的字号与字重并不一致。
- 12px 同时承担计数、域名、分类、时间、空态、脚注六种角色，信息密度高时整页发灰。

建议只定义五个角色，不再新增字号：

| 角色 | 字号/字重 | 用在哪 |
| --- | --- | --- |
| 页面名 | 13 / 600 | 标题栏 |
| 分组标题 | 13 / 600 | 目录头、卡片组头 |
| 行标题 | 14 / 600 | 收藏名、文件/小记主行 |
| 正文 | 13 / 400 | 小记正文、说明段 |
| 元信息 | 12 / 400 | 计数、域名、时间、分类、脚注 |

15px 保留给确实需要强调的数值或弹窗标题，不参与行级层次。

### 文件页类型位置不对称

文件行左侧是「扩展名色块 / 文件夹图标」，文件夹行右侧又额外出现一枚 12px「目录」。文件行右侧没有对应标签，于是：

- 右侧类型列只对文件夹存在，行尾节奏不齐；
- 「目录」与左侧文件夹图标重复表达同一件事；
- 文件类型在左、文件夹类型在左+右，扫视规则不一致。

建议删掉右侧「目录」标签，左侧图标已经足够；若坚持保留类型列，则文件与文件夹都应在右侧显示（PDF / DOCX / 目录），左侧改为统一图标，不能只给一种行加。

### Codex 两组页签同排同字号

「账号 / 会话 / 用量 / 回收站」是模块内视图，「今天 / 近 7 天 / 近 30 天 / 全部」是时间筛选，两者在同一页栏内并排、同为 13px，只有激活样式不同（药丸 vs 下划线）。层级不同却像同级页签。

建议在两组之间加 16–24px 间距 + 1px 竖分隔，或把时间筛选降为 12px 的分段控件；不要给两组都用药丸，否则更像两排同级导航。

### 用量图未来时段色块过重

「未到时段」用一整块实色矩形铺满图表右侧，面积接近一半，视觉重量超过真实数据。建议改为 2%–4% 的淡填充、斜线纹理或只留边界与标签，让已发生的小时曲线保持主角。

### 小记缺少搜索快捷键角标

收藏与文件页的搜索框右侧有 `Ctrl K` 键帽，小记同样监听了 Ctrl+K / ⌘K，但没有键帽。建议补同一枚 `.search-kbd`，三页的搜索可发现性一致。键帽文案继续用 `Ctrl K` / `⌘K`，与现有实现一致。

### 墨底 12px 辅助字低于基线

收藏卡片上的分类文字用 `--text-muted`，在 ink 卡片底 `#232427` 上实测约 5.53:1，低于项目对深色小字 5.8:1 的基线；域名用的 `--text-url` 已映射到 secondary，没有这个问题。建议墨色主题下把 12px 分类文字提到 `--text-secondary`，或把分类文字并入 secondary 的 URL 行，不单独用 muted。

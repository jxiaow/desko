## 1. 病根

- 侧栏只有 56px 图标轨，模块名与分组都不可见，八个模块靠记住图标；宽窗下左缘仍是一条窄轨道加整片空白。信息架构读不出来，是「太素」的第一来源。
- 收藏分类、小记视图与标签住在右侧 200–248px 的辅助目录里。它们本质是页面级导航，却为一个短列表常年让出一整列，还多出一颗只在筛选页出现的目录钮和一条 Ctrl+B。
- 默认 1040 窗同时存在 48px 顶栏、64px 页栏和右侧目录三层壳，正文被夹在中间；目录收起时右缘又空一片，密度两头都不讨好。
- 目录与小记/收藏深度耦合：承载位、展开/固定偏好、外部点击、Escape、窄窗自动收起和大量 E2E 都围着一个低频面板转。Codex 对话被 `CODEX_DIALOG_ENABLED = false` 屏蔽后，桌面目录已经没有实际消费者。

## 2. 结论

两个动作，同一轮落地：

1. **侧栏 148 ⇄ 56 两态**：展开态直接显示模块名和两个分组，收起态回到现有 56px 图标轨；开关常驻页头，状态按档案持久化，首帧前生效。
2. **页级工作栏 42px**：收藏分类、小记视图与标签从右侧目录回到页面内容列顶端；右侧目录层只留给 Codex，当前休眠。

另带一档卡面/纸面密度修正：卡片 80px、档面 26px，小记纸面 12/16/12/20、正文 22px 行高，全部去常态阴影。视觉身份仍是纸画布 + 浮岛卡 + 单列小记流，不引入表格、双栏索引、衬线或入场动画。

## 3. 几何

### 3.1 侧栏与折叠开关

| 窗口 | 状态 | 侧栏 | 开关左缘 x | 页名 / 正文左缘 x | 收藏列 |
| --- | --- | --- | --- | --- | --- |
| 1040 | 展开 | 148 | 148 | 180 | 3 列 |
| 1040 | 收起 | 56 | 56 | 88 | 3 列（更宽） |
| 900 | 展开 | 148 | 148 | 180 | 2 列 |
| 900 | 收起 | 56 | 56 | 88 | 2 列 |
| 1440 | 展开 | 148 | 197.5 | 229.5 | 4 列 |
| 1440 | 收起 | 56 | 151.5 | 183.5 | 4 列 |

开关绝对定位在 `.titlebar-page` 内、`left: -32px`，所以它永远落在页名左侧的 32px 内容留白里：

- 1040 / 900 的内容留白正好是 32px，开关左缘与侧栏接缝重合；
- 1440 内容列居中，留白变成 ~82px，开关跟着页名向内走，离接缝变远，但仍紧贴页名；
- 页名本身不被开关推开，始终与正文同一条竖轴；开关与侧栏在任何宽度都不重叠。

148px 的构成：12 边距 + 10 内距 + 20 图标 + 11 间距 + 73 文字 + 10 内距 + 12 边距 = 148。文字宽 73px 能放下最长模块名「局域网传输」（13px 约 65px），并留 8px 余量。

侧栏变宽后，1040 下正文列只剩 828px。收藏网格最小列宽从 280 收到 256、间距 12 收到 10，默认窗仍保 3 列，折叠后卡片变宽。小记阅读列继续吃 `--stream-max`，收窄只影响未到上限的窗口。

### 3.2 工作栏

- 高 42px（含 1px 底边），宽等于正文列（收藏 1120 / 小记 `--stream-max`），不伸进左右留白。
- 上距 8px，下距 12px；底部 1px `--border` 细线；无填充、无阴影，坐在画布上。
- 随内容滚动，**不吸顶**。小记日期头继续按工作区现状吸在内容顶端（`CodexWorkspace.vue` 已把 `.day-head` 压到 `top: 0`）。
- 单行，永不换行；实在溢出时横向滚动（滚动条隐藏），窗口本身不得出现横向滚动。

工作栏下方的第一块内容由它的 12px 下距接管：收藏网格 `margin-top` 归零、小记书写框 `margin-top` 归零，避免再叠一层 12px；其他模块的 `.content-inner` 上距保持 16px，只对含工作栏的页面收到 8px。

顶栏继续只放搜索和页内动作；工作栏只放筛选，不重复创建、选择、目录等动作。默认窗顶部壳从 48 + 64 = 112px 降到 48 + 42 = 90px，并收回右侧 200–248px 整列。

## 4. 侧栏

### 4.1 沿用的身份

- 纸 / 墨两套底色、`--bg-workspace-rail` 与主画布同源采光；品牌标 22px 不变。
- 侧栏与顶栏品牌格之间用 1px `--border` 接缝，展开/收起两态都保留；接缝从顶栏一直贯到窗底。
- 两态都没有宽度过渡：折叠是即时布局变化，不做动画。

### 4.2 展开态（默认）

- 容器：`padding: 8px 0 12px`，`border-right: 1px solid var(--border)`；导航纵向 stretch，组间距 2px。
- 品牌轴：品牌格 148px、左内距 15px，按钮内距 7px → Logo 左缘 22px，与导航图标左缘（12 边距 + 10 内距）同轴；字标左缘 53px，与导航文字左缘（22 + 20 图标 + 11 间距）同轴。字标 14px / 650，与 Logo 间距 9px。
- 分组题：12px / 500（`--text-xs`），`--text-muted`，`margin: 16px 12px 7px 22px`，首组上距 6px；右侧一条 `--border` 细线收到行尾。空分组整组不渲染。
- 行：38px 高，`width: calc(100% - 24px)`、`margin: 0 12px`、`padding: 0 10px`、圆角 9、图标 20、间距 11、字号 13、常态 `--text-secondary`。
- 激活：`--sidebar-active` 底 + `--text-brand` 文字（500）+ 行左缘 2px 强调条（上下各缩 9px）。强调条在行的左缘（x=12），不贴窗口最左缘。
- 底部设置行与导航同行档；`border-top: 1px solid var(--border)`，上距 10px。
- 名称已可见，不再显示 hover 气泡；`aria-label` 保留。

### 4.3 收起态

- `--sidebar-rail-w: 56px`；品牌格居中，字标隐藏，品牌按钮回到 36×36。
- 导航居中，导航块间距 10px；行 36×36、圆角 10、图标 20；组内 6px；组间在 10px 之外再补 6px（合 16px）；分组题隐藏。
- 名称和设置文字隐藏；激活回到现有配方：`--sidebar-active` 底 + `--text-brand` 图标，无左强调条。
- 折叠后分组题消失，这道额外 6px 就是两组之间唯一的分界。
- 名称靠 `data-tip` 气泡，只在收起态挂载；读屏继续读 `aria-label`。
- 底部设置钮 36×36，组内 4px。

### 4.4 折叠开关

- 28×28、圆角 7、`panel` 16px 图标、`--text-muted`；hover 吃 `--hover-chrome`，文字转 `--text`；焦点 2px `--accent` 外环。
- 位置：`.titlebar-page` 内、`.titlebar-left` 之前，`position: absolute; left: -32px; top: 50%; translateY(-50%)`。它是页头控件，不占品牌格、不占 36px 模块格，也不会被 `.titlebar-left` 的 `overflow: hidden` 裁掉。
- 语义：`aria-expanded` 跟随状态，`aria-controls` 指向侧栏根节点；`aria-label` / 提示在「收起侧栏」「展开侧栏」之间切换。
- 锁定态随顶栏一起隐藏，折叠状态保留；Web 与 Codex Web 不渲染。不新增键盘快捷键。

不放在侧栏内部：56px 时会和 Logo 抢同一格；展开时又会挤在模块列表顶上。不放在品牌格右侧：56px 下没有第二格，展开下会把品牌 lockup 推离左侧轴。

### 4.5 持久化与首帧

- 新设置键 `sidebar_collapsed`，值为 `'true' / 'false'`，缺省与无效值一律视为展开。
- 新服务 `src/services/sidebar.ts` 持有唯一状态源（模块级 `ref`，不用 Pinia：启动早于 `createApp`）：
  - `initializeSidebar()`：桌面读取设置，失败按展开处理，不回写；
  - `setSidebarCollapsed(value)`：乐观更新，按操作顺序串行保存；保存失败弹提示但保留当前交互状态（与目录偏好同方言）。
- `main.ts` 在 `createApp` / `mount` 之前 `await initializeSidebar()`，App 根节点首帧就带 `sidebar-collapsed` 类，不会先画展开再跳收起。
- 跟随当前档案；锁定/解锁不重读；Web 直接跳过读写，`sidebar_collapsed` 不加入 `WEB_PREFERENCES`。
- 采用条件：`.app-root.codex-layout:not(.web-runtime)` 才把 148 设为默认值，收起时覆盖为 56，避免污染 Web 的 216px 导航。

## 5. 页级工作栏

### 5.1 收藏

- 分类文字页签：13px、行内全高、间距 20px、左右 1px 内距；无图标；激活 `--text-brand` / 600，底部 2px 强调下划线沿用现有滑动滑块；计数一律 `--text-muted`，激活也不例外。
- 默认铺满可用宽度；装不下时保留能完整放下的前 N 个，再接「更多 (N) ▾」。选中项落在「更多」里时，触发器直接显示该分类名并带激活态，滑块跟过去。
- 下拉沿用现有面板：可搜索、选中即关闭、计数在右；键盘焦点与 Escape 行为不变。
- 分类仍是单选，「全部」永远第一颗；网格键盘导航、批量选择、详情弹窗不动。

### 5.2 小记

- 顺序：四个视图（全部 / 置顶 / 收藏 / 归档）→ 1px×15 竖分隔 → 标签。
- 视图：13px、全高、激活 `--text-brand` / 600 + 2px 下划线；计数 `--text-muted`。
- 标签：按现有 `tagCounts`（未归档口径）取前 4 个常驻；已选标签即使不在前 4 也常驻展示，顺序仍按计数；其余收进「更多标签 (N) ▾」。
- 标签下拉保持打开以支持多选；每行标签名 + 计数 + 选中勾；点外部 / Escape 关闭。已选标签之间没有 pill、没有下划线，只用 `--text-brand` / 600 表示。
- 归档视图不显示标签组，进入时清空已选标签：标签计数本来就不含归档条目，留着旧标签会得到一个没有任何可见原因的空白列表。返回其他视图不恢复旧标签。
- 不再单放「清空筛选」：关键词由搜索框的 × 清，标签逐颗点掉（标签本身就是开关）。
- 标签极多时整行横向滚动；已选标签全部保留在行内，不折行、不隐藏。
- 写作框、日期分组、批量底栏、归档上下文条的位置与行为不变；工作栏在它们之上。

### 5.3 极值

- 24 个分类 / 30 个标签：默认窗与 900 宽都不换行、不撑破窗口；更多面板内可搜索到全部项。
- 选中项被收进更多、标签多选、归档视图、空标签、模块被关掉、短窗 560 高，各自要有帧或断言。
- 脚本种子目前没有标签。落码前补一组「8 个标签 + 3 个已选」的纸 / 墨对照帧，确认标签区、分隔线和更多触发器的排版，再动 `src/`。

1. 1040×670 纸 / 墨 × 展开 / 收起 × 收藏 / 小记 = 8 帧，另加两张侧栏 zoom；与 `.tmp` 的 v15 帧一致（收藏工作栏上距从注入帧的 12 收到 8，落码后单独复核这 4px）。

## 11. 不做 / 否决

- 折叠钮放 56px 轨内：与 Logo 抢格，v9 已踩过。
- 折叠钮放品牌格右侧：56px 无第二格，展开态把品牌 lockup 推离左轴。
- 按窗口宽度自动折叠：状态会在边界抖动，也不该替用户改偏好。
- 保留右侧目录再叠折叠轨：两套筛选项、200px 列照旧，等于没解决。
- 把分类塞进 48px 顶栏：默认窗没有空间，搜索与动作会被压。
- 胶囊 / 分段控件做筛选：V5.2 已否 pill 筛选行；这里是页面导航，用文字 + 下划线。
- 工作栏加分类图标：同一排细描边图标会挤成一团，且分类是文字优先。
- 工作栏吸顶：会和日期头形成双层 sticky，多 42px 常驻壳；筛选随内容滚走，日期头继续吸顶。
- 激活计数用 `--text-brand`：12px 实测 4.41:1，低于基线；一律 muted。
- 侧栏宽度过渡：布局动画会让卡片重排，违背无入场动画与稳定密度。
- 字标塞进 56px 轨：v9 已把 Logo 挤成 0 宽，品牌格与导航必须共用两条竖轴。

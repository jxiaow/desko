# 桌面工作区布局

桌面正常启动默认使用已确认的工作区布局，不再依赖预览标记。Web 访问继续使用原有浏览器导航与设置。

## 布局与交互

- 外层顶栏保持 48px 通栏控制带：品牌、页名、计数、搜索和页内操作同排，右端为 Web 状态、备份徽标、锁定与窗口按钮。锁定排在最小化左侧，沿用窗口按钮的 34×30px 命中区与 14px 图标，锁定后隐藏入口；锁屏页的窗口按钮单独使用 30×26px、12px 图标和 6px 圆角，悬停背景随按钮收小。设置保留在图标轨底部，Desko 菜单通往档案管理与关于。顶栏页名使用固定宽度列，搜索位置不受名称和计数变化影响；窗口控件按实际占位独立保留空间。
- 图标轨宽 56px，轨内方块 36px、图标 22px、行距 4px，左右各留 10px。品牌标外盒同为 36px / 10px 圆角。Logo 区和图标轨与主画布同底色、同坐标采光，当前模块通过浅色选中反馈区分。页名与正文共用 32px 最小横向内距，宽窗一起居中到最大 1120px 阅读列；目录开关不切换内距档位。
- 小记视图与标签、收藏分类位于内容区域右侧，首次启动默认收起。
- 内容面保持通栏平面，不增加外框线或阴影。目录宽度为 `clamp(200px, 19vw, 248px)`，窄窗收窄、宽窗保留原有比例；目录无分隔描边，标题、行高和淡染选中底延续新骨架。选中项文字和图标使用 `--text-brand`。
- 页内控件继续通过 Teleport 放入通栏顶栏，维持 48px 单行。搜索最大 300px、最小 120px；目录展开时顶栏页名和操作与正文共同让位，不把正文操作放在目录上方。Codex 顶栏保留横向视图页签和操作按钮，页签采用 32px 高度、13px 字号、12px 横向内距与 4px 间距，保留下划线选中态。账号搜索与类型、状态、标签、排序一起放在内容筛选区；会话的标题/正文切换与搜索、用量的统计周期也位于各自内容区。内容搜索宽度为 180–300px，账号筛选空间不足时换行，长标签在最长 160px 的触发钮内单行省略。窄窗账号次级动作收为带完整名称及提示的图标按钮，创建入口仍显示文字，计数仅在空间充裕时显示。
- 目录在所有窗口宽度下均与正文并排停靠，展开时正文让出空间，收起后恢复可用宽度。
- 工具栏按钮和 Ctrl+B 切换当前模块目录。未固定时点外部或按 Escape 收起，窄窗选择筛选项也会收起。固定后保留展开，窄窗正文仍可点击；保留目录头的关闭按钮。目录按钮使用全局提示，不再同时显示组件气泡。
- 收藏、文件快捷、验证码与 Codex 页头创建按钮使用另一档主按钮：32px 高度、13px 加号与文字标签并排，文字与页栏次级按钮同档；表单确认按钮保留文字。
- 目录切换不卸载当前编辑器；全屏阅读或书写时，正文和辅助目录一起隐藏并退出背景焦点序列，退出全屏后恢复。目录内容独立滚动，预留稳定滚动条槽。
- 小记列表与阅读页只把明确设置为 H1–H6 的内容显示为标题。普通段落、引用与自动摘要均保持正文，不补造标题行；就地编辑的普通首段也不单独加粗。
- 无标题小记的正文直接从卡片上内边距开始，不保留空标题行。时间、状态和操作保持右上角，正文开头避让控件，后续文字恢复完整宽度；带明确标题格式的卡片保留原标题栏。
- 全屏阅读与书写的退出、状态和阅读操作并入 48px 通栏顶栏，使用 32px 控件与淡染编辑按钮；全屏时原页搜索、计数和目录让位，退出后恢复。正文直接呈现在工作区画布上，不再使用纸张卡片、描边或投影。阅读列采用 `clamp(800px, 80%, 1200px)` 上限并始终容纳于窗口内，窄窗保留 32px 水平留白，顶部留白 32px；书写列沿用 1200px 上限。标题栏与正文中的控件共用焦点循环，Escape 和退出后的焦点、滚动恢复行为保持一致。
- Codex 账号、会话、用量和回收站保持横向页签；用量时间范围采用次级分段筛选，保留原有统计窗口行为。
- 小记、收藏和文件搜索框使用一致的快捷键角标；文件夹类型只通过左侧图标表达。
- 普通卡片、撰写入口和拖放区保持新骨架的无边框、无常态阴影视觉，通过底色、留白和图标表达角色。仅选中、键盘聚焦和编辑时显示强调色反馈；悬停不得抹掉这些状态。搜索框沿用顶栏输入档。
- 内容区各模块的列表悬停共用卡面实底：浅色混入 2% 强调色以保留与画布的明度层次，深色混入 6% 以保持清楚的反馈。分组列表只改变当前行，卡片保持原位。行内动作底色随卡面变化，选中、批量勾选、编辑、禁用和加载状态保留各自反馈。

## 设置与恢复

桌面只保留纸、墨两种底色，强调色独立选择。浅色沿用纸的明亮内容面，绢归并到纸。主题、强调色与柔光仍使用原来的设置键。历史底色和强调色在读取时归并到可见选项，不在启动时回写。

- 雪、绢、雾 → 纸；岩、夜、苔 → 墨。更早的杏色先解析为绢，再归并到纸。
- 湖蓝、橄榄 → 绿；绯红 → 橙。
- 清新强调色在桌面保持原选择；Web 使用原有相近强调色。

墨采用中性的炭灰色阶：窗口、图标轨与内容共用画布 `#18191b`，卡片 `#26282c`。标题与正文使用 `#dfe1e5`，次级文字为 `#b7bfca`，元信息为 `#a4adba`，辅助文字为 `#a1aab7`；卡片上的小字在常态与悬停时均按 5.8:1 项目基线核验，并保留正文、次级文字与元信息之间的明度差。强调色用于操作、选中状态与环境光，正文和卡片保持中性实底。普通卡片无常态边框和阴影，标题保持 500 字重，焦点、选中及编辑反馈保留。

局域网传输和内网穿透运行中的停止按钮使用危险配色，常态、悬停及键盘按下时均由危险变体接管；通用主按钮规则排除该变体，禁用按钮仍使用统一禁用配方。

开启背景氛围时，常规弹窗和设置弹窗使用自身坐标中的左上主光与右下辅光，颜色跟随当前强调色，窗口放大或弹窗变小后仍可见。关闭氛围恢复纯色。输入框、卡片及全屏书写继续使用实底。

色彩层级参考 [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)的中性色与导航退后原则，以及 [Radix 色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)对背景、交互面、边界和文字的职责划分。预览以小记、Codex 会话和设置的真实页面核对；像素回归同时检查正文中性色、整窗同场、文字可读性和柔光实际变化。

`workspace_directory_open` 保存小记和收藏的展开偏好，`workspace_directory_pinned` 单独保存固定偏好，均为包含 `notes`、`entries` 布尔属性的 JSON 对象。手动收起不清除固定状态。设置属于当前档案，使用原生设置存储。启动时先恢复目录再检查解锁状态；不存在、无效或读取失败时默认收起且不固定。快速开关按操作顺序写入，保存失败显示提示并保留当前交互状态。

## Codex 用量与会话

账号与会话的未筛选总数不超过一条时，隐藏搜索与筛选；搜索后命中一条或零条仍保留控件，便于清除条件。删到只剩一条时清除隐藏的条件，显示剩余数据。

会话分组首次全部收起，刷新不自动展开；搜索时显示命中行，清空搜索恢复手动展开态。会话和用量页的统计口径统一放在默认收起的「统计说明」中，键盘与点击均可展开。页面保留关键数字、日期范围和必要标签，省去重复副标题与大段常驻说明。

模型用量明细中的会话标题可直接进入会话详情，清除此前的搜索词，按完整会话 ID 展开项目分组并聚焦目标行。同名标题不会混淆；会话已被外部移走时清除旧详情并显示提示。详情提供复制完整会话 ID、复制工作目录操作，沿用现有打开位置、打开文件和回收站能力。

账号添加弹窗保持固定尺寸，浏览器登录、设备码、API Key 与导入页签位于滚动正文之外。展开 Token 导入或切换字段时仅正文内部滚动，弹窗与页签位置不变。

## 验证入口

全部桌面 E2E 与生产使用同一启动路径，已移除经典布局测试切换开关。Web 通过浏览器运行环境验证自身布局。`workspace-layout-regressions.spec.ts` 覆盖阅读列上限、搜索与操作对齐、目录占位、选中颜色、编辑和聚焦悬停组合及长标签窄窗筛选；`workspace-refinements.spec.ts` 覆盖全高目录、固定、重启恢复、品牌菜单和页头创建按钮；`workspace-notes.spec.ts` 覆盖全屏隐藏与焦点行为；`workspace-visual-audit.spec.ts` 覆盖停止按钮三态与启停动作，以及墨色卡片小字对比度；`codex-session-link.spec.ts` 覆盖用量定位会话和会话被移走的路径。

主题恢复和目录持久化有独立单元测试。原生验证使用独立的 `com.desko.workspace-smoke` 档案和同一份生产前端产物；安装包使用正式标识 `com.desko.app`。

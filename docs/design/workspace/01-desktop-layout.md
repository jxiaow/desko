# 桌面工作区布局

桌面正常启动默认使用已确认的工作区布局，不再依赖预览标记。Web 访问继续使用原有浏览器导航与设置。

## 布局与交互

- 外层顶栏保留设置、锁定、备份和原生窗口控件，左上角 Desko 菜单通往档案管理与关于，左侧保留模块图标。
- 小记视图与标签、收藏分类位于内容区域右侧，首次启动默认收起。
- 内容面右侧外边距为 6px，底部为 3px。目录宽 200px，贴合内容面右缘与底部，使用中性底色、底部柔光和紧凑列表；选中项以实底和左侧强调标记区分，没有独立卡片外框或悬浮阴影。
- 目录在所有窗口宽度下均与正文并排停靠，展开时正文让出空间，收起后恢复可用宽度。
- 工具栏按钮和 Ctrl+B 切换当前模块目录。未固定时点外部或按 Escape 收起，窄窗选择筛选项也会收起。固定后保留展开，窄窗正文仍可点击；可通过关闭按钮手动收起。
- 收藏、文件快捷、验证码与 Codex 页头创建按钮使用 28px 淡底按钮与 14px 加号，保留名称与提示；Web 保留 40px 命中区，表单确认按钮保留文字。
- 目录切换不卸载当前编辑器；Codex 账号、会话、用量和回收站保持横向页签。

## 设置与恢复

桌面只保留纸、墨两种底色和十一种强调色。浅色沿用纸的明亮内容面，绢归并到纸。主题、强调色与柔光仍使用原来的设置键。历史底色和强调色在读取时归并到可见选项，不在启动时回写。

- 雪、绢、雾 → 纸；岩、夜、苔 → 墨。更早的杏色先解析为绢，再归并到纸。
- 湖蓝、橄榄 → 绿；绯红 → 橙。
- 清新强调色在桌面保持原选择；Web 使用原有相近强调色。

墨采用接近中性的炭灰色阶：外框 `#262625`、辅助面 `#191918`、正文 `#1e1e1d`、卡片与浮层 `#252524`。外框略亮于正文，避免大面积接近纯黑；标题与正文使用 `#cecdc8`，辅助信息降低明度，输入边界保持可见。柔光主要出现在外框和辅助面，正文通过更高的不透明遮罩减少整页泛灰。强调色继续用于操作、选中状态与辅助面底部的柔光，不改变正文底色的色相。

色彩层级参考 [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)的中性色与导航退后原则，以及 [Radix 色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)对背景、交互面、边界和文字的职责划分。预览以小记、Codex 会话和设置的真实页面核对；像素回归同时检查正文中性色、内容与外框分层、文字可读性和柔光实际变化。

`workspace_directory_open` 保存小记和收藏的展开偏好，`workspace_directory_pinned` 单独保存固定偏好，均为包含 `notes`、`entries` 布尔属性的 JSON 对象。手动收起不清除固定状态。设置属于当前档案，使用原生设置存储。启动时先恢复目录再检查解锁状态；不存在、无效或读取失败时默认收起且不固定。快速开关按操作顺序写入，保存失败显示提示并保留当前交互状态。

## Codex 用量与会话

模型用量明细中的会话标题可直接进入会话详情，清除此前的搜索词，按完整会话 ID 展开项目分组并聚焦目标行。同名标题不会混淆；会话已被外部移走时清除旧详情并显示提示。详情提供复制完整会话 ID、复制工作目录操作，沿用现有打开位置、打开文件和回收站能力。

账号添加弹窗保持固定尺寸，浏览器登录、设备码、API Key 与导入页签位于滚动正文之外。展开 Token 导入或切换字段时仅正文内部滚动，弹窗与页签位置不变。

## 验证入口

全部桌面 E2E 与生产使用同一启动路径，已移除经典布局测试切换开关。Web 通过浏览器运行环境验证自身布局。`workspace-refinements.spec.ts` 覆盖固定、重启恢复、品牌菜单和图标创建操作；`codex-session-link.spec.ts` 覆盖用量定位会话和会话被移走的路径。

主题恢复和目录持久化有独立单元测试。原生验证使用独立的 `com.desko.workspace-smoke` 档案和同一份生产前端产物；安装包使用正式标识 `com.desko.app`。

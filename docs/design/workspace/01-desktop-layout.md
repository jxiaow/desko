# 桌面工作区布局

桌面正常启动默认使用已确认的工作区布局，不再依赖预览标记。Web 访问继续使用原有浏览器导航与设置。

## 布局与交互

- 外层顶栏保留设置、锁定、备份和原生窗口控件，左上角 Desko 菜单通往档案管理与关于，左侧保留模块图标。
- 小记视图与标签、收藏分类位于内容区域右侧，首次启动默认收起。
- 内容面右侧外边距为 6px，底部为 3px。目录宽 200px，贴合内容面顶部、右缘与底部，作为正文旁的全高列；目录头高 64px，标题使用 13px / 500 和辅助正文色，名称为「视图与标签」或「收藏分类」。目录使用中性底色、底部柔光和紧凑列表，选中项与模块导航共用淡染底和左侧强调标记，没有独立卡片外框或悬浮阴影。
- 页栏只占正文列，常态最小高度 64px；控件外盒不超过 32px，窄窗允许换行。搜索框共享 360px 最大宽度，可随空间收缩。网络直连的 36px 探测行属于页内表单，保留独立尺度。
- 目录在所有窗口宽度下均与正文并排停靠，展开时正文让出空间，收起后恢复可用宽度。
- 工具栏按钮和 Ctrl+B 切换当前模块目录。未固定时点外部或按 Escape 收起，窄窗选择筛选项也会收起。固定后保留展开，窄窗正文仍可点击；保留目录头的关闭按钮。目录按钮使用全局提示，不再同时显示组件气泡。
- 收藏、文件快捷、验证码与 Codex 页头创建按钮使用 28px 淡底按钮与 14px 加号，保留名称与提示；Web 保留 40px 命中区，表单确认按钮保留文字。
- 目录切换不卸载当前编辑器；全屏阅读或书写时，正文和辅助目录一起隐藏并退出背景焦点序列，退出全屏后恢复。目录内容独立滚动，预留稳定滚动条槽。
- 小记列表与阅读页只把明确设置为 H1–H6 的内容显示为标题。普通段落、引用与自动摘要均保持正文，不补造标题行；就地编辑的普通首段也不单独加粗。
- 无标题小记的正文直接从卡片上内边距开始，不保留空标题行。时间、状态和操作保持右上角，正文开头避让控件，后续文字恢复完整宽度；带明确标题格式的卡片保留原标题栏。
- 全屏阅读纸面随可用内容宽度展开，采用 `clamp(800px, 80%, 1200px)` 上限并始终容纳于窗口内；窄窗保留两侧至少 20px 留白，纸面内边距保持 20×28px。最大化后正文同步变宽，超宽屏仍限制行长；书写列沿用 1200px 上限。
- Codex 账号、会话、用量和回收站保持横向页签；用量时间范围采用次级分段筛选，保留原有统计窗口行为。
- 小记、收藏和文件搜索框使用一致的快捷键角标；文件夹类型只通过左侧图标表达。
- 搜索框与小记撰写入口默认采用同档普通边框色且无阴影，聚焦时使用强调色边框与焦点环；撰写面展开后保留卡片底色和书写反馈。

## 设置与恢复

桌面只保留纸、墨两种底色，强调色独立选择。浅色沿用纸的明亮内容面，绢归并到纸。主题、强调色与柔光仍使用原来的设置键。历史底色和强调色在读取时归并到可见选项，不在启动时回写。

- 雪、绢、雾 → 纸；岩、夜、苔 → 墨。更早的杏色先解析为绢，再归并到纸。
- 湖蓝、橄榄 → 绿；绯红 → 橙。
- 清新强调色在桌面保持原选择；Web 使用原有相近强调色。

墨采用中性的炭灰色阶：外框 `#121315`、辅助面 `#1b1c1f`、正文 `#18191b`、卡片 `#232427`。标题与正文使用 `#dfe1e5`，次级文字为 `#b7bfca`，元信息为 `#a4adba`，辅助文字为 `#a1aab7`；卡片上的小字在常态与悬停时均按 5.8:1 项目基线核验，并保留正文、次级文字与元信息之间的明度差。强调色用于操作、选中状态与环境光，正文和卡片保持中性实底。普通卡片使用轻边框、无常态阴影和 500 字重标题，焦点、选中及编辑反馈保留。

局域网传输和内网穿透运行中的停止按钮使用危险配色，常态、悬停及键盘按下时均由危险变体接管；通用主按钮规则排除该变体，禁用按钮仍使用统一禁用配方。

开启背景氛围时，常规弹窗和设置弹窗使用自身坐标中的左上主光与右下辅光，颜色跟随当前强调色，窗口放大或弹窗变小后仍可见。关闭氛围恢复纯色。输入框、卡片及全屏书写继续使用实底。

色彩层级参考 [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)的中性色与导航退后原则，以及 [Radix 色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)对背景、交互面、边界和文字的职责划分。预览以小记、Codex 会话和设置的真实页面核对；像素回归同时检查正文中性色、内容与外框分层、文字可读性和柔光实际变化。

`workspace_directory_open` 保存小记和收藏的展开偏好，`workspace_directory_pinned` 单独保存固定偏好，均为包含 `notes`、`entries` 布尔属性的 JSON 对象。手动收起不清除固定状态。设置属于当前档案，使用原生设置存储。启动时先恢复目录再检查解锁状态；不存在、无效或读取失败时默认收起且不固定。快速开关按操作顺序写入，保存失败显示提示并保留当前交互状态。

## Codex 用量与会话

会话分组首次全部收起，刷新不自动展开；搜索时显示命中行，清空搜索恢复手动展开态。会话和用量页的统计口径统一放在默认收起的「统计说明」中，键盘与点击均可展开。页面保留关键数字、日期范围和必要标签，省去重复副标题与大段常驻说明。

模型用量明细中的会话标题可直接进入会话详情，清除此前的搜索词，按完整会话 ID 展开项目分组并聚焦目标行。同名标题不会混淆；会话已被外部移走时清除旧详情并显示提示。详情提供复制完整会话 ID、复制工作目录操作，沿用现有打开位置、打开文件和回收站能力。

账号添加弹窗保持固定尺寸，浏览器登录、设备码、API Key 与导入页签位于滚动正文之外。展开 Token 导入或切换字段时仅正文内部滚动，弹窗与页签位置不变。

## 验证入口

全部桌面 E2E 与生产使用同一启动路径，已移除经典布局测试切换开关。Web 通过浏览器运行环境验证自身布局。`workspace-refinements.spec.ts` 覆盖全高目录、固定、重启恢复、品牌菜单和图标创建操作；`workspace-notes.spec.ts` 覆盖全屏隐藏与焦点行为；`workspace-visual-audit.spec.ts` 覆盖停止按钮三态与启停动作，以及墨色卡片小字对比度；`codex-session-link.spec.ts` 覆盖用量定位会话和会话被移走的路径。

主题恢复和目录持久化有独立单元测试。原生验证使用独立的 `com.desko.workspace-smoke` 档案和同一份生产前端产物；安装包使用正式标识 `com.desko.app`。

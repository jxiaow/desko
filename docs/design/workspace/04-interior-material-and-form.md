## 1. 现状的实测

真应用（`vite --mode e2e` + `__E2E_CONFIG__` 种子），1040×670，纸 / 墨各一套：

| 项 | 纸 | 墨 |
| --- | --- | --- |
| 画布底色 | `rgb(246,246,244)` | `rgb(24,25,27)` |
| 卡片底色 | `rgb(255,255,255)` | `rgb(38,40,44)` |
| 卡与画布明度差 | 9 级（对比 1.08:1） | 14 级（1.19:1） |
| 卡面常态阴影 | 无 | 无 |
| 卡面常态描边 | 1px 但透明 | 1px 但透明 |
| 圆角 | 全部 12 | 全部 12 |
| 卡内距 | 全部 14/16/14/16 | 同左 |
| 顶栏高度 | 48 | 48 |
| 侧栏 | 56px 图标轨，5 个模块，**文字 0 个** | 同左 |
| 页名字号 | 16px / 600 | 同左 |
| 栏内主钮 | accent 10% 淡染底 | accent 10% 淡染底 |

三处"锁页有、内页没有"的断裂：

1. **锁页的光场，内页没有。** 锁页 `.unlock-bg` 恒有两团径向光（`--lock-orb` 派生），实测左上 `234,243,246`、右下 `246,246,244`，蓝味差 12 级。内页 `data-atmosphere` 默认 `off`（`DEFAULT_APPEARANCE.backgroundAtmosphere = false`），画布四点取样全是 `246,246,244`，**零梯度**。用户从锁页解锁进内页，第一眼看到的是同一块灰掉了下来——锁页攒起来的光没有延续。
2. **锁页的呼吸，内页没有。** 锁页题词用衬线（`Songti SC`），`docs/design/lock-screen/01-ambient-aura.md` 记的三团 24s/28s/32s 漂移光晕是锁页唯一的品牌记忆。内页零动效、零衬线、零纹理，只有 HarmonyOS Sans 一套字。
3. **锁页的留白，内页换成等宽卡海。** 锁页是居中 300px 内容栈；内页是 13 张 296×88 等宽白卡铺成三列，视觉节拍是"胶囊海"——这正是 2026-09-29 那轮反馈"普通笨重"的原话，而当时的 B 档（列表去胶囊）只落在了收藏 / 文件两页的行列表上，后来又被 03 的卡面四档统一成网格卡，把行制收回了。

两处**实现与文档不符**（不是审美问题，是账对不上）：

4. **悬停把卡片沉到画布之下。** `01-desktop-layout.md` 第 25 行写"浅色混入 2% 强调色以保留与画布的明度层次"，但 `CodexWorkspace.vue:83` 实现的是 `color-mix(in srgb, var(--text) 7.5%, var(--bg-surface))`。实测纸底卡片常态 `255`，悬停 `238`，而画布是 `246`——**悬停后卡片比画布还暗 8 级**，指针压下去卡片反而"沉"进背景。墨底同向但幅度小（`38→46`，画布 `24`）。
5. **纸底面板档收白档的结论没落到工作区。** `distinctive/01-plan.md` 记的"纸底卡片收白档"结论是 `--panel-bg #ffffff → #fcfcfc`，理由是"收两档起，卡片与画布只剩 6 级，行内字母块、输入槽、代码底开始和卡面糊在一起，故否"（否掉的是更狠的收法，选了收一档）。但当前 `workspace-themes.css:37` 与 `global.css:147` 都还是 `#ffffff`——工作区根本没吃到那个收档的结论。

## 2. 提案：三档，逐档可停

对拍帧：`.tmp/proposal-ab2/compare/proposal-compare.png`（三档 × 双主题 × 收藏 / 小记），单帧在同目录。

### A 档 · 现状

HEAD 原样。不必多说。

### B 档 · 材质连续（改 4 处，风险最低）

| 改动 | 依据 | 实测效果 |
| --- | --- | --- |
| 光场默认开 | 锁页恒有光、内页恒无光；氛围配方与开关都已存在 | 纸底画布左上 `234,243,246` → 右下 `246,246,244`，光回来了；墨底 `27,32,37` → `24,25,27` |
| 悬停改混 2%/6% 强调色 | 回到 `01` 文档第 25 行的原话 | 悬停不再沉到画布之下 |
| 页名 16 → 18px | 顶栏只留一处强层级 | 与 03 文档 §6 一致 |
| 栏内主钮墨底实心 | 淡染档读作标签不像可点 | 与 03 文档 §6 一致 |

这四条里有三条是 03 文档已经写好、只差点头的。B 档单独就能落地，**不依赖 03 的骨架改造**。

### C 档 · 形制归一（收藏页回行制）

收藏是**清单**：名字 + 副址要能竖着扫读。13 张等宽卡壳挡在中间，每张卡自己是一个小房间，行与行之间没有共同的栏，等于把一张表拆成 13 个独立对象在读。

行制实测（`.tmp/proposal-ab2/C-rows-*.png`）：

| 项 | 网格卡（现状） | 行制（C 档） |
| --- | --- | --- |
| 卡高 | 88 | 44（减半） |
| 首屏可读行数 | 13 条占 3 屏高 | 13 条占 1 屏高 |
| 卡面壳 | 白底 + 圆角 + 透明描边 | 无底、无圆角、无描边，只留一根发丝线 |
| 行尾空带 | — | 分类文字右缘离内容列右缘 49px（网格卡下是 673px 的大片死区） |
| 悬停 | 洗底 | 洗底 + 分类淡出、动作浮岛占住行尾（沿用现状方言） |

行制不是新发明。`distinctive/01-plan.md` 的 B 档"列表去胶囊"当年就通过了，落地在 `.rowlist`（整表白卡 + 行间发丝线）；后来 03 的卡面四档统一把收藏收成网格卡，行制又丢了。C 档是把 B 档那套语言**用行制**（不是整表白卡）重新接回来，和 03 的"无常态阴影、无常态描边、层次由底色阶梯承担"不冲突。

行制的行尾一格必须二选一：常态放分类文字，hover 时淡出、动作浮岛顶上。两者同时在会字面重叠——实测动作浮岛 `895–981`、分类文字 `967–991`，确实压在一起，所以分类必须淡出。

## 3. 与既有结论的关系

- **不推翻 03。** 03 的骨架（侧栏 148⇄56 两态、页级工作栏 42px、目录退役）是几何层，本文是材质层与形制层，两条并行。03 §6 的卡面四档在收藏页要按 C 档改写为行制，其余七页不受影响。
- **不推翻 distinctive 的否决项。** 呼吸头部（A 档大字标题）、胶囊筛选行、表格、双栏索引、衬线正文、常态阴影——一条都不提。
- **恢复两个丢掉的结论**：悬停混强调色（`01` 文档第 25 行）、纸底收白档（`distinctive` 记录）。
- **锁页是基准，不是要改的对象。** 锁页一个字不动；内页向锁页靠。

## 5. 验收

1. 1040×670 纸 / 墨，收藏 13 条：首屏可见 13 条，行高 44，卡面无底色、无圆角、无描边，行间 1px `--border`。
2. 悬停：分类文字淡出到 0，动作浮岛出现，两者字面不重叠；纸底悬停后卡片明度不低于画布。
3. 光场：内页画布四点取样有梯度（纸底左上蓝味差 ≥ 8 级）；关掉氛围后回到纯色，两态都拍帧。
4. 页名 18px / 26 行高，≤900 宽回 16px；顶栏只有这一处强层级。
5. 栏内主钮墨底实心，纸底 `rgb(36,35,33)` + 白字、墨底自动反白，对比度 ≥ 4.5:1。
6. 小记页不受 C 档影响（它本来就是内容卡流），B 档的页名 / 主钮 / 光场照常生效。
7. `node scripts/check-theme-coverage.mjs` 不新增违例（96 槽契约不动）。
8. `npx vue-tsc --noEmit`、`npx vitest run`、`npx playwright test` 全绿。

## 6. 不做 / 否决

- 不给内页加衬线正文：锁页的衬线是题词的独白，内页正文要保持可扫读的密度。
- 不给内页加常驻动效：光场是静态材质，漂移动效仍只属于锁页。
- 不给卡面加回描边或投影：层次由底色阶梯承担（03 §11 已否）。
- 不改小记的卡片流：便签内容天然不等高，胶囊海那一套不适用于它。
- 不动验证码页的三列网格：那是多值并置的仪表面，行制会毁掉并置比较。
- 不把氛围光做成常驻动画：那是锁页的例外，不是内页的默认。

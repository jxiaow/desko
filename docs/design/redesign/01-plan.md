# desko 整体重设计 v2：北极星 + 四层方案（提案，待拍板）

日期：2026-09-26 ｜ 前置：`.design-qa/DESIGN_QA_REPORT.md`（走查基线）、行卡/弹窗/骨架三条基线（本轮全部可复审）

授权范围：用户确认视觉风格、布局结构、信息架构、交互模式四层全重做，**允许打破** 96 槽令牌契约与三条 UI 基线。本文档只提案，未拍板不动代码。

## 1. 问题诊断：为什么要推倒

现状本质是"五个同构列表页"：page-bar + 搜索 + 行卡列表 ×5，外加悬停浮出的动作排。分层看：

- **视觉**：灰底浮白卡 + 四桶分类色当界面色，气质更接近"文件管理器"而不是"工作台"；七套主题摊薄了每一套的打磨度，视觉记忆点弱。
- **布局**：五模块内容性质差异很大（收藏=检索表、小记=流、验证码= glance 卡片、传输=状态页），却被塞进同一个容器形态。
- **信息架构**：模块间平铺没问题，但模块内二级导航各页一套（收藏分类 tab、小记左 rail、文件分组），语言不统一。
- **交互**：动作靠悬停（一行最多 9 颗），发现性差；批量模式是一个平行状态，进出有认知成本；编辑=整卡换脸。

## 2. 北极星

**"工作台，不是表格。"** 安静的工具：界面退到灰阶，色彩全部让给内容；每个动作一眼可见；五模块各自成形，不再共用一个模板。

参考坐标：Things 3（列表工具的从容）· Linear（密度与键盘友好）· Notion 就地编辑（写作即本体）。

## 3. 四层方案

### A. 视觉语言 —— "纸与墨"

- 界面层只保留中性灰阶 + 一个品牌 accent；分类色从界面退到内容侧（只在徽章/标签里出现），行卡、导航、工具条不再吃四桶色。
- 主题 **7 → 2（一浅一深）+ 4 档 accent 任选**。九十六槽契约重立为约六十槽，"改主题四处联动"的维护面直接减半，每一套都能打磨到位。
- 字体沿用 HarmonyOS Sans SC；对比拉大：页面题 20/600、正文 14/400、元信息 12，行卡主标题从 15 回落到 14，让内容而不是卡片标题当主角。
- 表面语言：单层卡面 + 发丝分隔线；悬停不再抬阴影，改描边显色 + 底色微变（动效只剩 0.1~0.15s 的颜色过渡，无入场动画）。

### B. 布局结构 —— 每页各自成形

全局骨架：左侧 **48px 图标 rail**（悬停出 label，当前项 accent 指示条）+ 内容区。1040×670 基准下：

| 模块 | 新容器 | 关键变化 |
| --- | --- | --- |
| 网址收藏 | 双栏：左 160px 分类列 + 右行卡列表 | 64px 两行卡形制**保留**（已验证资产）；<960px 分类列塌缩为顶部 chips |
| 小记 | 单列流 | 左 rail 废除，视图筛选改顶部 chips 行；就地编辑 + 顶部动作条（刚定稿的形态）保留 |
| 文件快捷 | 分组列表（按盘/目录分组头） | 行语言同收藏 |
| 验证码 | 卡片网格，一行 2~3 张 | 验证码大数字升为主角（等宽 24px+），issuer 退为小字 |
| 局域网传输 | 状态页：上状态卡（速率/设备）+ 下历史表 | 从"列表页"改成"仪表盘"，仅此页例外 |

多栏只在 ≥960 生效，窄窗一律塌成单栏 + chips——不做常驻三段。

### C. 信息架构

- 五模块平等 + 设置，**不做首页、不做聚合面板、不做命令面板**（既往否决继续有效）。
- 模块内二级分类统一为一个组件：chips 行（收藏分类 / 小记视图 / 文件分组共用），废除各页自制导航。
- 锁页、验证码口令、备份流程：交互流程不动，视觉跟随新皮。
- 弹窗层**豁免本轮**：底栏 46px/28px 钮、字段 32px 的弹窗基线已过走查，只换皮不换骨。

### D. 交互模型

- **悬停动作排 → "主动作常驻 + ⋯ 次动作"**：每行悬停只浮出 1~2 颗主动作（编辑/复制/打开），其余进 ⋯ 菜单；菜单只放独有低频项，不与快捷图标重复（disclosure-dedup 规矩）。
- **批量模式 → 勾选 + 底部浮出操作条**：取消"批量态"这个平行状态，勾上任一行的复选框即浮出操作条，清空即收起。
- 键盘：Enter/Space 激活行卡（已落地）保留；⋯ 与主动作可 Tab 达到；Esc 关层、Cmd+Enter 保存不变。
- 双击仍不作任何核心入口。

**变革稿与吸收式落地（2026-09-26 追加拍板）**：保守稿之外另出变革稿 `proto-bento/`（每页=重点区+全量区：收藏 4×2 常用磁贴+46px 紧凑列表、小记头版一条+双列瀑布、验证码 Hero 大码+用码统计+队列）。用户裁定：**皮肤（配色/图标/样式）认可、排版先不吸收**；随后进一步拍板——**把「除排版外」的改动吸收进现 app，布局保持现状**，具体为：

1. **主题契约 7→2+4**：底色两套——`paper`（纸，暖灰浅底，基准 #f5f4f1）/ `ink`（墨，暖中性深底）；accent 四档——墨蓝 ink #3d5a80、青瓷 celadon #3d7355（承锁页第四轮母版）、赭石 clay #9a5b33、紫罗 plum #5f62b8。实现取两轴结构：`[data-theme]` 两块填全部基础槽，`[data-theme=x][data-accent=y]` 覆盖层只填 accent 族槽（accent/hover/active/on/soft/light/ring、text-brand、badge-ver-*、brand-g*、lock-orb-*、selection、toast-info）。**槽名本期不缩编**（96→60 的缩槽留 R4），避免全组件改名的大波及。旧 7 ID 进迁移表：五浅→paper、两深→ink；accent 就近映射（warm→clay、celadon→celadon、linear-dark→plum、其余→ink）。设置库新增 `accent` 键。
2. **分类色退内容侧**：侧栏五枚模块色相钉改中性灰、激活态用 accent；界面层色彩全部走新灰阶。`--cat-*` 槽保留但只供内容侧（头像/色相钉浓淡）使用。
3. **图标语言**：侧栏图标本已是线性 currentColor，仅改着色规则（常显中性、激活 accent），随 2 一并落。
4. **批量模式**：废除显式"批量态"开关——复选框常显（hover 强化），勾选即浮底部 dock、清空即收。dock 骨架（`.batch-dock`）沿用已过走查的基线。
5. **不做**：bento 布局（磁贴区/头版/队列）、④ 使用频次统计（打开计数/用码统计卡）——后者为唯一被搁置的功能新增，待布局议题另行拍板。

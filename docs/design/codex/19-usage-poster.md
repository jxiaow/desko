### 2.1 视觉原则

- **一张卡只讲一件事**：总量是主角，构成回答「花在哪」，主图回答「什么时候」，模型回答「谁用的」。同一数据不再换图形重复。
- **今日折线，其余堆叠柱**：今日是一条连续时间轴，折线回答「用量怎么起落」，只连已开始的小时；周 / 月 / 全部是离散的日子，堆叠柱回答「每天由什么构成」。现在线按真实时间落在 12:30，而不是 12:00 桶边界。
- **总量不借分段色**：折线、峰值点、面积都走品牌青瓷，不使用净输入蓝——折线是三段合计，用任一数据色都会被读成单一分段。
- **空态也是设计态**：无数据时只留基线、0 和「暂无本地用量记录」，不伪造 140万 刻度，也不把「未到时段」当主角。
- **深浅两套固定配色**：纸 / 墨底 + 青瓷品牌色 + 与用量页同源的三枚数据色；不跟随用户强调色，分享图保持稳定识别。品牌只出现「Desko」与「Codex 用量」，不出现账号、邮箱、会话、路径。

- 深色不是绿调近黑：底、线、轨道分别取应用墨色体系的中性档，避免上一版整张发绿。

### 3.3 版面与区块

- 顶部：左品牌（6×28 竖条 + Desko + 1×18 分隔线 + Codex 用量），右范围胶囊（7px 圆点 + 今日 / 近 7 天 / 近 30 天 / 全部，40px 高、全圆角、1px 线）。
- kicker 行：左「总 Token」，右 period（今日 `2026-10-20 · 本地时间`；周 / 月 `起 — 止`；全部 `全部本地会话记录`）。
- 主数字：`formatTokenCount` 结果；下方 `Intl.NumberFormat('zh-CN')` 完整数字 + `tokens`。右栏依次请求数、会话数、可选估算金额，右对齐；关金额只少一行，不占空槽。
- 构成：标题「用量构成」；右侧「缓存命中占 N%」。20px 高构成条按净输入 / 缓存命中 / 输出分三段，段间 3px 留缝；下方三等分图例，每项色点 + 标签 + 值 + 占比。
- 主图：标题（今日「每小时用量」，其余「每日用量」）+ 右侧峰值；全部范围在标题下补一行「最近 30 天 · 起 — 止」，因为主数字是全量、主图只画最后记录附近的 30 天。
- 模型：顶部细线，标题「主要模型」+ 右侧「按 Token 占比」；最多三行，每行名称 / 8px 轨道 + 品牌色填充 / Token 数 / 占比；有 `otherModels` 时行下补「另有 N 个模型」。
- 页脚：贴底；有金额时先免责声明再品牌行，无金额时只留品牌行；左「● Desko · 本地用量统计」，右「截至 日期 时间」。

### 3.4 主图规则

- 今日 24 个小时桶（夏令时按当天实际小时数）；周 7 天；月 / 全部 30 个自然日（数据层已是固定窗口，不压缩时间轴）。
- x 轴标签：今日 `00 / 04 / 08 / 12 / 16 / 20 / 23`，7 天全标；30 天标 `0 / 7 / 14 / 21 / 末` 五个，避免挤字。标签以所在桶的中心对齐，不再用 `space-between` 的端点对齐。
- y 轴：0 / 半程 / 上限三条虚线。上限 = `ceil(max * 1.1 / step) * step`，`step = 10^floor(log10(peak)) / 5`，与现有口径一致（110万 → 140万，50万 → 60万）。空态只画 0 基线。
- 今日折线：数据点位于小时桶中心，只连已开始的小时，未来小时不补 0；3px 品牌色实线、圆角端点，线下铺同色 16% → 0 的面积；峰值点 9px 实心 + 3px 底色描边。不画末尾端点圆点，现在线就是有效数据的右边界。
- 柱子：仅周 / 月 / 全部使用，堆叠净输入 / 缓存命中 / 输出，柱宽 `min(列宽 × 0.62, 36px)`，柱顶 3px 圆角；不做峰值描边，不改变数据色。
- 未来桶不铺色块、不画柱 / 点、不写「未到时段」；今日画一条 1px 虚线现在线，位置 = 当天已过时长 / 全天时长，标签「现在 HH:mm」。现在线只在今日出现。
- 峰值文案：今日 `峰值 11:00 · 110万`；周 / 月 / 全部 `峰值 10-20 · 50万`；空态 `峰值 —`。
- 空态：基线 + x 标签 + 现在线，中央一枚圆角底板写「暂无本地用量记录」；不画假刻度。

## 4. 数据与实现

### 4.1 数据快照

`UsagePosterData` 只加一个字段：

```ts
/** 今日主图现在线位置：0–1；其它范围为 null */
nowRatio: number | null
```

在 `usagePosterData()` 里按 `(updatedAt - dayStart) / (nextMidnight - dayStart)` 计算并夹到 0–1；`dayStart = fromTimestamp`，与 `usageHours` 同一口径。它只是比例，不含时间戳、账号或路径，分享快照的隐私边界不变。`trendPeriod` 保留，仅供全部范围的图下说明。

其余字段沿用：`range/title/period/asOf/filename/totals/points/models/otherModels`。`points` 已带 `label/future`；今日标签为 `HH:mm`，其它为 `MM-DD`。

### 4.2 渲染器

重写 `src/utils/codexUsagePoster.ts` 的 `renderUsagePoster()`；`USAGE_POSTER_SIZE`、`usagePosterData()` 的对外形状不变（除新增 `nowRatio`）：

1. 加载 HarmonyOS Sans SC；创建 Canvas、铺底与环境光。
2. 画顶部品牌行 / 胶囊、kicker、主数字 + 右栏；右栏按 `showCost` 动态成组。
3. 画构成条与三等分图例；`fresh = max(0, input - cached)`，总分母用 `totalTokens`，零时只画轨道。
4. 算主图的上限、刻度与 x 标签；画虚线网格；今日画品牌色折线、面积与峰值点，其余范围画堆叠柱；再叠现在线；空态走 3.4 的空分支。
5. 从页脚向上算模型区与主图区高度，模型 1–3 行 + `otherModels` 说明；保证页脚贴底、无固定死区。

旧的 `plot()` 复用两次小图、未来块、蓝色折线 + 端点全部删除；保留「今日折线 / 其余柱」的双图形，但今日折线改为品牌色 + 面积 + 峰值点，不再借用净输入蓝。预览弹窗 `CodexUsageShareDialog.vue` 不动：它只负责 3:4 预览、主题 / 金额开关、保存与复制，现有状态机已覆盖重绘竞态。

## 6. 拍板结论

| 决策 | 本轮建议 | 理由 |
|---|---|---|
| 海报是否带 Desko 品牌 | **带**，左上竖条 + Desko，右上范围胶囊 | 分享出去是一张有出处的卡，不再是匿名报表；不出现账号等隐私 |
| 配色是否跟随用户强调色 | **不跟**，固定青瓷 + 数据色 | 用量页数据色是语义色，海报跨设备 / 跨主题需要稳定识别；现有实现也是固定两套 |
| 今日是否保留未来时段提示 | **不保留**，只画现在线 | 当前「未到时段」色块比数据还重；现在线已经说明有效区间 |
| 主图是否保留两张独立刻度小图 | **删除** | 净输入 / 输出已由构成条与主图（今日折线 / 其余堆叠柱）表达，重复且挤掉主图高度 |
| 零态刻度 | **只留 0 基线**，不伪造上限 | 空图不该看起来像有数据；中央说明足够 |

今日折线已由用户在 2026-10-21 拍板保留，不再作为待选项；本轮只调整它的颜色、面积与未来桶处理。

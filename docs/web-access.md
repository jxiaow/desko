# Web 访问

> 2026-10-27：Codex 对话已屏蔽——`src/services/featureFlags.ts` 的 `CODEX_DIALOG_ENABLED = false` 收掉桌面「Codex → 对话」页签和「设置 → Web 访问」里的 Codex Web UI 服务卡片。本文关于 Codex 对话与 Codex Web UI 的段落留作实现记录；前端组件与 Rust `codex_bridge` 未删除，改回 `true` 即恢复。

在桌面版解锁 Desko，打开「设置 → Web 访问」，分别启动所需的服务。浏览器使用**当前档案的桌面主密码**登录，无需单独设置 Web 密码。两个服务使用独立进程、端口及登录会话，可以分别停止：

| 服务 | 默认本机入口 | 用途 |
|---|---|---|
| Desko Web | `http://127.0.0.1:8420` | 小记、收藏、文件等完整 Web 工作区 |
| Codex Web UI | `http://127.0.0.1:8421/codex` | 已屏蔽：Codex 对话、任务、审批与工作区改动 |

端口可修改；Codex Web UI 随对话功能屏蔽，当前「设置 → Web 访问」只列出 Desko Web。

需要手机或其他电脑访问时，勾选「允许局域网设备访问」并确认，在同一网络打开页面提供的局域网地址。Windows 防火墙可能需要允许 Desko 访问专用网络。局域网使用 HTTP，适合可信的家庭或办公网络。

服务运行时，桌面标题栏显示带圆点的「Web」标识，悬停可查看访问范围与端口；解锁状态下点击可直达 Web 设置。停止服务后标识消失。

Web 支持七个模块：

- 小记：编辑、待办、归档、图片、加密、解锁、解除加密，以及小记口令的设置、修改和找回。
- 网址收藏：查看、添加、编辑、删除、复制账号口令和访问网址。
- 文件快捷：浏览、下载桌面端已收藏的文件和目录。子目录不能跳出收藏根目录；添加本机路径和终端操作由桌面端完成。
- 验证码：查看、复制、添加、移除，支持用浏览器选择二维码图片。
- Codex：账号添加、授权、导入、导出、编辑、配额刷新、切换与回收站管理；会话标题和正文搜索、Token 与用量统计、查看及下载会话 JSONL、移入回收站和恢复。浏览器默认使用设备码授权，OAuth 回跳不可达时可粘贴回调地址。
- 局域网传输：查看状态、启停、管理共享目录、端口和传输口令；从当前浏览器选择或拖入文件上传到电脑的共享目录。单文件上限 4 GiB，同名文件自动避让。
- 内网穿透：接入授权、程序获取、隧道与服务登记、公网策略、连接检查和启停管理。

七个模块均与桌面共用模块开关。关闭后，浏览器入口和对应页面不可访问，全部关闭时显示首页空态；未开启的模块可在浏览器「设置 → 模块」中开启。开关变化会同步到其他在线浏览器与桌面，关闭服务模块会同时停止对应服务。

浏览器与桌面共用最新工作区设计及纸、墨两套底色。外观、目录开关与固定状态、粘贴整理格式开关、Codex 配额刷新偏好单独保存在当前浏览器。设置中也提供小记口令修改、模块开关、局域网传输配置和 Codex 配额设置。

Codex Web UI 登录后直接进入对话。填写运行 Desko 的电脑上的工作目录，或选择已使用的目录；Windows / WSL 环境与桌面相同。CLI 在该电脑执行，手机本地的目录不适用。桌面与 Web 使用各自的运行连接，Web 上的任务和审批可在其他已登录的 Codex Web 浏览器中继续查看。浏览器不提供原生文件选择器及历史索引导入按钮，导入可在桌面完成。

主密码用于桌面解锁与 Web 登录；小记口令仍与桌面使用同一把，保护加密正文所需的密钥。忘记小记口令时，与桌面一样，使用已登录主密码对应的密钥封条找回，再设置新口令。Web 不保存另一套密码或重新加密一份数据。

加密小记在每个浏览器登录会话中分别解锁；一个浏览器解锁、锁回或退出，不改变其他浏览器和桌面端的小记状态。重新登录后小记恢复锁定。仅属于加密小记的图片访问及附件操作，同样要求当前浏览器已解锁对应小记。

浏览器退出不锁定桌面版；桌面锁定和重新解锁不影响 Web 访问，Web 登录也不会自动解锁桌面。更换主密码、切换档案、恢复备份或停止 Web 服务会使旧 Web 会话失效，需要在桌面端重新启动服务并登录。空闲 30 分钟或登录满 12 小时也需要重新登录。

桌面浏览器的内容列随窗口宽度居中。手机通过标题栏左侧按钮打开模块抽屉，抽屉底部可进入设置；选择模块后自动收起。右侧目录以覆盖方式展开，保留正文宽度和工具栏按钮位置。竖屏与横屏均使用单列内容和常显操作，批量操作栏位于底部安全区域上方。Codex 对话在窄屏下通过「对话」按钮展开历史列表，「改动」打开覆盖面板；消息、输入框和审批保留完整宽度。

Web 面的中文使用系统字体，桌面内嵌的那颗中文字体只在桌面版加载，浏览器首屏因此不必搬运它；两端字形观感略有差异。不含用户数据的编译产物按文件名哈希长期缓存，字体缓存一周；页面、接口、附件与下载内容始终不缓存，换设备或清理浏览器缓存后会重新拉取。公网访问的实测账目与取舍见 `docs/design/web/02-tunnel-perf.md`。

服务每次手动启动，由桌面管理和回收；退出 Desko 后两个服务一起停止。关闭 Codex 模块会停止 Codex Web UI 及其 CLI 连接。Web 进程通过随机密钥保护的本机内部通道访问桌面的数据上下文，不自行打开第二份数据库或继承桌面的小记解锁状态；公开 HTTP 服务没有任意原生命令入口。备份、档案切换、网络直连和系统终端操作仍在桌面端完成。

开发验证：`cargo test -p desko --manifest-path src-tauri/Cargo.toml web_access` 检查鉴权、会话、下载和内部通道；`node scripts/web-perf.mjs <访问地址> --browser` 对拍公网面首屏的出网字节、字体请求与二次访问复用，判据与账见 `docs/design/web/02-tunnel-perf.md`；构建后运行 `node scripts/tests/web-worker-smoke.mjs` 验证真实独立进程的启动、登录隔离、停止、重启与父进程控制通道关闭后的退出。冒烟使用内存数据，不启动 Codex CLI 或模型任务。

构建后也可运行 `cargo test -p desko --manifest-path src-tauri/Cargo.toml separate_worker_processes -- --ignored`，直接验证 Rust 启动器、Windows Job、worker 崩溃回收、数据代次失效退出及另一服务持续可用。该测试只启动无窗口的内存 fixture 服务。

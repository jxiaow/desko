# Web 访问

在桌面版解锁 Desko，打开「设置 → Web 访问」，直接启动服务。浏览器使用**当前档案的桌面主密码**登录，无需单独设置 Web 密码。默认仅能在这台电脑访问 `http://127.0.0.1:8420`，端口可以修改。

需要手机或其他电脑访问时，勾选「允许局域网设备访问」并确认，在同一网络打开页面提供的局域网地址。Windows 防火墙可能需要允许 Desko 访问专用网络。局域网使用 HTTP，适合可信的家庭或办公网络。

服务运行时，桌面标题栏显示带圆点的「Web」标识，悬停可查看访问范围与端口；解锁状态下点击可直达 Web 设置。停止服务后标识消失。

Web 支持七个模块：

- 小记：编辑、待办、归档、图片、加密、解锁、解除加密，以及小记口令的设置、修改和找回。
- 网址收藏：查看、添加、编辑、删除、复制账号口令和访问网址。
- 文件快捷：浏览、下载桌面端已收藏的文件和目录。子目录不能跳出收藏根目录；添加本机路径和终端操作由桌面端完成。
- 验证码：查看、复制、添加、移除，支持用浏览器选择二维码图片。
- Codex：账号添加、授权、导入、导出、编辑、配额刷新、切换与回收站管理；会话标题和正文搜索、Token 与用量统计、查看及下载会话 JSONL、移入回收站和恢复。浏览器默认使用设备码授权，OAuth 回跳不可达时可粘贴回调地址。
- 局域网传输：查看状态、启停、管理共享目录、端口和传输口令；从当前浏览器选择或拖入文件上传到电脑的共享目录。单文件上限 4 GiB，同名文件自动避让。
- 内网穿透：接入授权、程序获取、隧道与服务登记、公网策略、连接检查和启停管理。

Codex、局域网传输和内网穿透与桌面共用模块开关。未开启时，可在浏览器「设置 → 模块」中开启；开关变化会同步到其他在线浏览器与桌面。关闭服务模块会同时停止对应服务。

浏览器外观和 Codex 配额刷新偏好单独保存在当前浏览器。设置中也提供小记口令修改、模块开关、局域网传输配置和 Codex 配额设置。

主密码用于桌面解锁与 Web 登录；小记口令仍与桌面使用同一把，保护加密正文所需的密钥。忘记小记口令时，与桌面一样，使用已登录主密码对应的密钥封条找回，再设置新口令。Web 不保存另一套密码或重新加密一份数据。

加密小记在每个浏览器登录会话中分别解锁；一个浏览器解锁、锁回或退出，不改变其他浏览器和桌面端的小记状态。重新登录后小记恢复锁定。仅属于加密小记的图片访问及附件操作，同样要求当前浏览器已解锁对应小记。

浏览器退出不锁定桌面版；桌面锁定和重新解锁不影响 Web 访问，Web 登录也不会自动解锁桌面。更换主密码、切换档案、恢复备份或停止 Web 服务会使旧 Web 会话失效，需要在桌面端重新启动服务并登录。空闲 30 分钟或登录满 12 小时也需要重新登录。

桌面浏览器的内容列随窗口宽度居中。手机使用可横向滑动的底部模块导航、单列内容和常显操作，支持竖屏与横屏；批量操作栏位于导航上方，弹窗按可用视口收缩。

服务每次手动启动，退出 Desko 后停止。备份、档案切换、网络直连和系统终端操作仍在桌面端完成。局域网传输与内网穿透的访问策略、口令继续由各自模块管理。

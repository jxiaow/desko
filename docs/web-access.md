# Web 访问

在桌面版解锁 Desko，打开「设置 → Web 访问」，设置至少 8 位的访问密码后启动服务。默认仅能在这台电脑用浏览器访问 `http://127.0.0.1:8420`，端口可以修改。

需要手机或其他电脑访问时，勾选「允许局域网设备访问」并确认，在同一网络打开页面提供的局域网地址。Windows 防火墙可能需要允许 Desko 访问专用网络。局域网使用 HTTP，适合可信的家庭或办公网络。

Web 使用单独的访问密码，支持：

- 小记：编辑、待办、归档、图片和小记加密操作。
- 网址收藏：查看、添加、编辑、删除、复制账号口令和访问网址。
- 文件：浏览、下载桌面端已收藏的文件和目录。子目录不能跳出收藏根目录；添加本机路径和终端操作由桌面端完成。
- 验证码：查看、复制、添加、移除，支持用浏览器选择二维码图片。

浏览器外观单独保存在当前浏览器。浏览器退出不锁定桌面版；Web 独立持有本次服务的解锁状态，桌面锁定和重新解锁不影响浏览器访问，也不会被 Web 登录自动解锁。更换主密码、切换档案、恢复备份或停止 Web 服务会使旧 Web 会话失效，需要在桌面端重新启动服务并登录。空闲 30 分钟或登录满 12 小时也需要重新登录。

服务每次手动启动，密码只保留在本次运行内存中，退出 Desko 后停止。网络配置、Codex 账号切换、备份和系统命令在桌面端操作。
